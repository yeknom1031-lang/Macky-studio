# ゆるモン大行進

絵本・切り絵・フェルトの世界を冒険する、横スクロール型ラインディフェンスゲームです。

## 遊び方

**`index.html` をブラウザで開くと、そのまま遊べます。** インストールやビルドは不要です。Mac では `遊ぶ.command` をダブルクリックしても起動できます。

ホームの「冒険に出かける」→ステージを選ぶ→「このステージへ出発」で開始します。

- 時間とともに貯まる魔力で、下のカードから仲間を召喚します。
- 仲間は自動で歩き、敵を攻撃します。敵拠点を破壊すると勝利です。
- 盾役・遠距離・範囲攻撃・回復の組み合わせがカギになります。
- 「回復力UP」で魔力の回復速度と上限が増えます。
- 「森の大砲」は敵全体を攻撃して押し戻します。チャージは30秒です。
- オート操作、2倍速、一時停止、全画面表示に対応しています。
- キーボード：`1`〜`6` で召喚、`Q` で回復力UP、`Space` で大砲、`Esc` で一時停止。
- スマートフォンでは各ボタンをタップ。戦場を広く見たいときは横向きがおすすめです。

## 遊べる内容

- 3エリア、12ステージ、3回のボス戦
- 味方8種、敵4種、6枠の自由な編成
- 最大20レベルの育成、HP割合による三つ星評価
- ランダムな仲間の召喚、敵の出現パターン、戦場のエフェクト
- 4回ごとの未加入キャラクター確定召喚。重複時は育成資源に変換
- 第1・第2エリアクリアでも、未加入の仲間を確定解放
- 勝利・敗北のリザルト、ステージ再挑戦、全ステージ踏破
- ブラウザ内への自動保存、セーブの書き出し・読み込み、効果音設定

ゲーム内の資源だけで遊べます。課金・広告・外部アカウントはありません。

## セーブ

同じブラウザ、同じURLで遊ぶと続きから再開できます。HTTPでの起動とファイルを直接開く場合は、それぞれ別のセーブになります。別のブラウザに移る場合は、設定からセーブを書き出して読み込んでください。進行・所持資源・編成は保存されますが、戦闘中の状態は保存されません。

## 画像素材

前回の8枚の画面コンセプトをもとに、OpenAIの内蔵画像生成で実装用画像を**6枚**追加しました。今回の使用上限200枚以内です。

- `assets/characters.png`：透過キャラクターアトラス（味方8体・敵4体）
- `assets/castles.png`：透過拠点アトラス（味方・敵）
- `assets/meadow.png`：はじまりの森
- `assets/night.png`：月あかりの湖
- `assets/sunset.png`：夕やけの丘
- `assets/home.png`：ホームの村

共通指定は「切り絵・フェルト・クレヨンの絵本風、やわらかな自然色、オリジナルモンスター、文字なし」です。全生成プロンプトは `assets/prompts.json` に保存しています。アニメーション、UI、数値、ボタン、効果音はプログラムで生成します。元のコンセプト画像は `../assets/yurumon-ui/` に残しています。

## 開発・確認

Node.js があれば `npm start` または `node server.mjs` で `http://127.0.0.1:4178` を開けます。ポートは `PORT` 環境変数で変更できます。ゲーム本体に外部ライブラリは必要ありません。

`npm test` または `node --test tests/core.test.cjs` で、戦闘、資源、召喚、セーブの復元、報酬の重複防止、全12ステージの進行を検証できます。

`tests/browser-smoke.cjs` は Playwright と Chrome を使い、ホーム→育成→召喚→編成→戦闘→勝利→再読み込みまで検証します。`PLAYWRIGHT_MODULE` と `CHROME_PATH` でインストール先を指定できます。画面写真は `tests/artifacts/` に出力されます。
