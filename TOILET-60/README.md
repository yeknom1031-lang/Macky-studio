# あと60秒で限界です。 — 混雑サバイバル版 v3

棒人間のトイレ探索サバイバル。公共施設・学校・駅・モール・公園・オフィスの雰囲気を残して、48ステージを広い迷宮に拡張しました。

## いつでも遊ぶ

Macでは **「いつでも遊ぶ.command」をダブルクリック**すると、同じフォルダの完成版がChromeで開きます。**index.htmlを直接ブラウザで開く**こともできます。サーバーの起動、インストール、ネット接続は不要です。以前の `127.0.0.1:8765` という一時的なプレビューURLは使いません。

画像・ルール・画面・音の生成処理をHTMLに内蔵しています。約24MBのindex.htmlだけをコピーしても遊べます。起動用commandを使う場合はindex.htmlと同じフォルダに置いてください。

プレイ中は5秒ごと、一時停止時、ページを閉じる際に自動保存します。次回はタイトルの「つづきから」で、残り時間・位置・アイテム・開いた近道・探索済み地図・会話の残り時間・息切れを引き継ぎ、一時停止した状態から再開できます。保存枠は直近のプレイ1件です。新しいゲームの開始で上書きされ、クリア・敗北で消えます。

## 操作とルール

- WASD / 矢印キー：移動。見えている床のクリック・タップでも移動できます。
- Shift：急ぐ。残り時間も通常の1.35倍で減ります。約4.2秒の連続ダッシュで息切れし、回復するまで歩きます。下部の「息の余裕」で確認できます。
- E / Space：トイレに入る・待つ、仕掛けを調べる、仲間を誘う、案内係に聞く。
- Q：仲間にトイレを譲る。必要な秒数を見て判断してください。
- M：探索済みの全体地図。地図を見ている間は時計が止まります。
- Esc / P：一時停止。別のタブやアプリに移動したときも自動停止します。
- タッチ操作：画面下の方向ボタン・急ぐ・アクション。

空いているトイレに入って3秒過ごすとクリア。使用中なら音を手がかりに、待つか別を探すかを決めます。待機中は空き次第自動入室し、移動すると待機をやめます。人に接触すると立ち話に捕まり、3〜9秒間移動・入室できません。会話中も時計は進みます。歩いていても接触すると止められ、走ってぶつかると会話が2秒長引きます。通路の脇を使って距離をとりましょう。

仲間を誘うと3秒回復。案内係は2秒を使って全トイレの位置を教えてくれます。回復は開始時の制限時間が上限です。

## 広さ・ランダム要素

| 難易度 | 制限時間 | マップの大きさ | 部屋・分岐 | トイレ | 通行人 |
| --- | --- | --- | --- | --- | --- |
| Easy | 180秒 | 83 × 62マス | 88 | 3 | 22 |
| Normal | 120秒 | 97 × 76マス | 130 | 2 | 28 |
| Hard | 75秒 | 90 × 69マス | 108 | 2 | 34 |

Normalは旧32×22マスの約10.5倍の面積です。探索に合わせてカメラが移動します。小さい90秒の練習マップも残しています。

トイレは従来の8か所から2〜3か所へ減らしました。各ステージは13種類・計62個のアイテムと仕掛け、鍵つきの近道6か所を含みます。部屋の形、通路、アイテム、ロッカーの中身、近道、トイレの待ち時間がseedに応じて変わります。

「プレイごとに配置を変える」は標準でオン。オフにすると各ステージの固定配置で遊べます。失敗後の「同じマップで再挑戦」は元のseedを維持します。「新しい配置で挑戦」なら同じ場所の雰囲気で別の迷宮になります。全48ステージを最初から選択できます。

鍵つきの通路は追加の近道だけです。鍵がなくても全エリアへ到達でき、すべてのトイレまでの通路を確保します。通常ステージでは開始時はすべて使用中です。空き時間を過ぎると再び清掃中・使用中になるため、到着時の状態を確認してください。中に入った後の3秒間に追い出されることはありません。

## 新しい難しさ

- **4種類の通行人**：おしゃべり好き、アンケート係、おすすめ係、巡回スタッフ。種類・難易度・衝突時の走行状態で会話時間が変わります。Eでこちらから話すこともできます。
- **立ち話の時間ロス**：会話はスキップできません。残り秒数とセリフを表示します。終了後2.5秒は再び捕まらず、同じ人も22秒間は話しかけません。一時停止中は会話の時計も止まります。
- **トイレの空き時間**：短い空き時間と使用・清掃が交互に来ます。入口の表示、音、待機を使って判断します。仲間に譲った場合は、仲間が出てから5秒は続けて入れます。
- **息切れ**：走りっぱなしにはできません。ダッシュを止めると少し待って回復し、35%以上で再び走れます。練習では息切れしません。
- **工事と走行禁止**：資材の上は速度が42%に低下。縞模様の「歩いて」エリアを走って踏むと−5秒。歩くか脇を通って避けます。
- **回復を希少に**：キャンディを8個から3個、休憩ベンチを3か所から1か所、キーカードを8枚から4枚へ減らしました。

## 素材・保存

画像生成で6エリア分の素材画像を制作。各画像に床・別の床・壁・壁の細部を収めた、計24種類のテクスチャーを使用しています。原本と生成プロンプトは `assets/textures/` にあります。キャラクターは表情と動きのある棒人間のままです。

クリア記録と途中保存はブラウザのlocalStorageに保存します。ブラウザのデータ削除、別のブラウザへの変更、HTMLの移動で別の保存領域になることがあります。旧HTTPプレビュー版とfile版の保存先も別です。保存が制限されていてもプレイできますが、終了後まで記録を保持できません。強制終了時は最後の自動保存時点からの再開になります。

旧v2の途中保存も読み込めます。位置・残り時間・鍵・開いた近道などを引き継ぎ、トイレ・仕掛け・通行人は新版の配置に切り替えます。旧版で待機・入室途中だった場合は、その位置から探索を再開します。クリア記録は残ります。

## 編集・検証

- `src/core.js`：ゲームルール・マップ生成・途中保存
- `src/render.js`：生成テクスチャー・棒人間・地図の描画
- `src/app.js`：画面・入力・音・記録・自動保存
- `src/style.css` / `src/shell.html`：見た目とHTMLの土台
- `assets/textures/`：6つの生成画像とプロンプト

このフォルダ内で実行します。

```sh
python3 build.py
node --test tests/core.test.cjs tests/dungeon.test.cjs tests/challenge.test.cjs
node tests/browser.cjs
node tests/dungeon-browser.cjs
node tests/challenge-browser.cjs
```

ブラウザテストにはPlaywrightとGoogle Chromeが必要です。通常のプレイには不要です。検証結果は `TEST-REPORT.md` と `test-results/` に保存しています。

ステージは `src/core.js` のSTAGESにID・テーマ・seedを追加して増やせます。同じ生成器と素材を使うため、手作業でマップを描く必要はありません。編集後は到達性のテストとビルドを実行してください。
