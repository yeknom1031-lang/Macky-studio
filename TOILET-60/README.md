# あと60秒で限界です。

棒人間のトイレ探索サバイバル。**index.html をダブルクリック**して遊べます。インストール、サーバー、ネット接続は不要です。画像・音声・フォントを外部から取得しません。

## 操作

- WASD / 矢印キー：移動。見えている床のクリックでも移動できます。
- Shift：急ぐ。移動は速くなりますが、残り時間も通常の1.35倍で減ります。
- E / Space：近くのトイレに入る・待つ / 仲間を誘う / 案内係に聞く。
- Q：トイレで仲間に先を譲る。仲間が必要な秒数を伝えます。
- Esc / P：一時停止。別のタブやアプリに移動すると自動で停止します。
- スマートフォン：下部の方向ボタンとアクションボタン。床のタップでも移動できます。

トイレに入ってから3秒経過するとクリアです。使用中のトイレは、水を流す音などで空く時刻を予想できます。待つことを選ぶと空き次第自動で入ります。移動で待機をやめられます。走って人にぶつかると2秒減ります。

仲間を誘うと3秒回復します（開始時の上限まで）。案内係は2秒を使って全トイレの位置をミニマップに表示します。未探索の通路は歩いて見つけましょう。

## 内容

48ステージ（公共施設・学校・駅・モール・公園・オフィス各8面）、ランダムマップ、3難易度（90 / 60 / 30秒）、小さい練習マップ、記録保存、称号、敗北時の経路表示、音量調整、動きを抑える設定を収録しています。すべてのステージを最初から選べます。

ステージと難易度が同じなら配置・待ち時間が同じになります。再挑戦で道順を覚えられます。Hardは短時間向けの小さなマップになります。全マップに到達できるトイレと、制限時間内にクリア可能な経路を確保します。

記録はブラウザのlocalStorageに保存します。ブラウザのデータ削除、別のブラウザへの変更、HTMLの移動で記録が消えたり別扱いになったりすることがあります。保存が制限されていてもゲーム自体は動作します。

## 編集・ビルド

`src/core.js` がルールと生成器、`src/render.js` が共通タイル・棒人間の描画、`src/app.js` が画面と操作、`src/style.css` がUIです。

```
python3 build.py
node --test tests/core.test.cjs
node tests/browser.cjs
```

ブラウザテストにはPlaywrightとChromeが必要です。通常のプレイには不要です。テスト結果は `test-results/` に保存します。

## マップを増やす

`src/core.js` のSTAGESでID・テーマ・seedを指定すれば、同じ素材から別のレイアウトが生成されます。THEMESで壁・床の色と小物を設定できます。ルートの連結と到達性のテストを実施してから `build.py` でHTMLへ反映してください。
