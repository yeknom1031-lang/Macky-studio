# あと60秒で限界です。 — ダンジョン版 v2

棒人間のトイレ探索サバイバル。公共施設・学校・駅・モール・公園・オフィスの雰囲気を残して、48ステージを広い迷宮に拡張しました。

## いつでも遊ぶ

Macでは **「いつでも遊ぶ.command」をダブルクリック**すると、同じフォルダの完成版がChromeで開きます。**index.htmlを直接ブラウザで開く**こともできます。サーバーの起動、インストール、ネット接続は不要です。以前の `127.0.0.1:8765` という一時的なプレビューURLは使いません。

画像・ルール・画面・音の生成処理をHTMLに内蔵しています。約24MBのindex.htmlだけをコピーしても遊べます。起動用commandを使う場合はindex.htmlと同じフォルダに置いてください。

プレイ中は5秒ごと、一時停止時、ページを閉じる際に自動保存します。次回はタイトルの「つづきから」で、残り時間・位置・アイテム・開いた近道・探索済み地図を引き継ぎ、一時停止した状態から再開できます。保存枠は直近のプレイ1件です。新しいゲームの開始で上書きされ、クリア・敗北で消えます。

## 操作とルール

- WASD / 矢印キー：移動。見えている床のクリック・タップでも移動できます。
- Shift：急ぐ。残り時間も通常の1.35倍で減ります。
- E / Space：トイレに入る・待つ、仕掛けを調べる、仲間を誘う、案内係に聞く。
- Q：仲間にトイレを譲る。必要な秒数を見て判断してください。
- M：探索済みの全体地図。地図を見ている間は時計が止まります。
- Esc / P：一時停止。別のタブやアプリに移動したときも自動停止します。
- タッチ操作：画面下の方向ボタン・急ぐ・アクション。

空いているトイレに入って3秒過ごすとクリア。使用中なら音を手がかりに、待つか別を探すかを決めます。待機中は空き次第自動入室し、移動すると待機をやめます。走って人にぶつかると2秒減ります。

仲間を誘うと3秒回復。案内係は2秒を使って全トイレの位置を教えてくれます。回復は開始時の制限時間が上限です。

## 広さ・ランダム要素

| 難易度 | 制限時間 | マップの大きさ | 部屋・分岐の数 |
| --- | --- | --- | --- |
| Easy | 180秒 | 83 × 62マス | 88 |
| Normal | 120秒 | 97 × 76マス | 130 |
| Hard | 75秒 | 90 × 69マス | 108 |

Normalは旧32×22マスの約10.5倍の面積です。探索に合わせてカメラが移動します。小さい90秒の練習マップも残しています。

各ステージはトイレ8か所、11種類・計62個のアイテムと仕掛け、鍵つきの近道6か所を含みます。部屋の形、通路、アイテム、ロッカーの中身、近道、トイレの待ち時間がseedに応じて変わります。

「プレイごとに配置を変える」は標準でオン。オフにすると各ステージの固定配置で遊べます。失敗後の「同じマップで再挑戦」は元のseedを維持します。「新しい配置で挑戦」なら同じ場所の雰囲気で別の迷宮になります。全48ステージを最初から選択できます。

鍵つきの通路は追加の近道だけです。鍵がなくても全エリアへ到達でき、必ず最初から空いているトイレへの経路を確保します。

## 仕掛け

| 種類 | 遊び方 |
| --- | --- |
| ひと息キャンディ | 拾うと+12秒 |
| かけ足シューズ | 拾うと10秒間、移動速度アップ |
| キーカード | 近道の前でE。鍵を1枚使って開く |
| 探検メダル | 集めた枚数をクリア結果に表示 |
| 濡れた床 | 足が遅くなる。走ると滑って−2秒 |
| 動く歩道 | 矢印の方向は速く、逆方向は遅くなる |
| お楽しみロッカー | Eで時間・鍵・シューズのどれかを入手 |
| 休憩ベンチ | Eで1回だけ+20秒 |
| 館内案内図 | Eで全通路・トイレ・仕掛けの場所が分かる |
| 連絡エレベーター | Eで対になる遠い出口へ。仲間も同行 |
| 開閉スイッチ | Eで同じ番号の近道を開く。鍵不要 |

## 素材・保存

画像生成で6エリア分の素材画像を制作。各画像に床・別の床・壁・壁の細部を収めた、計24種類のテクスチャーを使用しています。原本と生成プロンプトは `assets/textures/` にあります。キャラクターは表情と動きのある棒人間のままです。

クリア記録と途中保存はブラウザのlocalStorageに保存します。ブラウザのデータ削除、別のブラウザへの変更、HTMLの移動で別の保存領域になることがあります。旧HTTPプレビュー版とfile版の保存先も別です。保存が制限されていてもプレイできますが、終了後まで記録を保持できません。強制終了時は最後の自動保存時点からの再開になります。

## 編集・検証

- `src/core.js`：ゲームルール・マップ生成・途中保存
- `src/render.js`：生成テクスチャー・棒人間・地図の描画
- `src/app.js`：画面・入力・音・記録・自動保存
- `src/style.css` / `src/shell.html`：見た目とHTMLの土台
- `assets/textures/`：6つの生成画像とプロンプト

このフォルダ内で実行します。

```sh
python3 build.py
node --test tests/core.test.cjs tests/dungeon.test.cjs
node tests/browser.cjs
node tests/dungeon-browser.cjs
```

ブラウザテストにはPlaywrightとGoogle Chromeが必要です。通常のプレイには不要です。検証結果は `TEST-REPORT.md` と `test-results/` に保存しています。

ステージは `src/core.js` のSTAGESにID・テーマ・seedを追加して増やせます。同じ生成器と素材を使うため、手作業でマップを描く必要はありません。編集後は到達性のテストとビルドを実行してください。
