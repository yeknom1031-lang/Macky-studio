# MAGMA ESCAPE

マグマ・エスケープ・アスレチック。生成した3D風アートを使った、縦画面の2Dサバイバルゲームです。

## 遊ぶ

このフォルダで `npm start`、または `node server.mjs` を実行し、<http://localhost:4188> を開きます。Macでは `ゲームを起動.command` をダブルクリックして起動できます。依存パッケージのインストールやビルドは不要です。

| 操作 | パソコン | スマートフォン |
|---|---|---|
| 左右移動 | ← → / A D | 左下の ‹ › |
| ジャンプ | Space / ↑ / W | JUMP |
| ジェット | E / Shift 長押し | JET 長押し |
| 一時停止 | Esc | 左上の Ⅱ |

足場は1mごと。ジャンプボタンは押し直すと再ジャンプします。ジェット燃料は足場に立つと回復します。ホームの操作ガイドでも確認できます。

## 実装済み

- 上昇するマグマ、無限の足場生成、通常・移動・点滅・崩壊の4種の足場
- 0〜50m、51〜100m、101m以降の難易度変化。崩壊は通常0.5秒、上級0.36秒
- ジェット、空腹、体力、コイン回収、追従カメラ、着地・獲得エフェクト
- 15mから約15m間隔のショップ（着地時に発生）、おにぎり・マグマ肉
- 12mからの制限時間付きクイズ、22mからのタイミングバトル
- 移動速度・ジェット飛行時間の5段階の永続強化
- コインガチャ、5種のオーラ、確率表示、重複還元、装備・コレクション
- リトライ、リザルト、記録保存、効果音と簡易BGM、音量ON/OFF、演出軽減
- キーボードと複数ポインターによる左右＋ジャンプの同時操作
- ウィンドウのフォーカス喪失・バックグラウンド移行時の自動停止
- PWA manifest、アイコン、Service Workerによる初回読み込み後のオフライン起動

イベントは着地してから順番に処理します。途中で足場を飛び越した場合、次の着地で発生します。ショップ・クイズ・バトル中はマグマと空腹の消費が止まります。

## データとPWA

セーブは `localStorage` の `magma-escape.v1`。コイン、強化、所持オーラ、装備、最高記録、設定を保存します。初回150コイン。進行中のプレイはページ再読み込みで終了します。ブラウザの保存データ削除で記録も消えます。アカウント、課金、オンラインランキングはありません。

本番配信はHTTPSの静的ホスティングにこのフォルダをそのまま置けます。相対パスなのでサブディレクトリにも対応します。iPhoneではSafariの共有メニューからホーム画面に追加します。LAN内のHTTPでゲームは動きますが、PWAのオフライン機能はHTTPSまたはlocalhostが必要です。

更新時は `sw.js` の `CACHE` のバージョンを変更します。旧版を開いている間は新版を待機させ、全タブを閉じた後の起動で切り替えます。プレイ途中に別バージョンの素材を混ぜません。

## 構成

- `core.js`: DOMに依存しない固定タイムステップのゲームロジック、経済・セーブ正規化
- `renderer.js`: Canvas 2Dの描画、生成画像のアトラス、マグマとエフェクト
- `app.js`: 画面、入力、イベント、永続化
- `audio.js`: Web Audioによる効果音と控えめなBGM
- `assets/`: 同梱済みの生成画像8枚、アプリアイコン2サイズ、スプライト座標
- `art-prompts.json`: 実際の画像生成プロンプト。built-in image_gen使用
- `art-sources.json`: この制作セッションの元画像パス記録
- `tools/prepare-assets.mjs`: 生成画像のWebP圧縮とアルファ境界の測定。再実行時のみsharpが必要
- `tests/core.test.mjs`: 物理、足場、経済、保存、ガチャの自動テスト
- `tests/browser.mjs`: Chromeによる画面遷移、操作、保存、オフライン、モバイル画面テスト
- `tools/simulate.mjs`: 20シードでジャンプを続ける簡易操作シミュレーション

本体は外部CDNやランタイム依存なし。実行に使う生成画像一式は約2.1MB。画像は制作時に生成済みで、プレイ中に生成APIへの通信・課金は発生しません。

## 検証

`npm test` でロジックテストを実行します。ブラウザテストはChrome、Playwright、起動済みのローカルサーバーが必要です。`MAGMA_PLAYWRIGHT` にPlaywrightパッケージのパスを指定することもできます。

```sh
node --test tests/core.test.mjs
node tests/browser.mjs
node tools/simulate.mjs
```

Chromeでゲーム開始、短いキー入力、ポーズ、設定、強化、残高不足、ガチャ、装備、食事、クイズ、バトル、死亡、再読み込み後の保存、オフライン再起動を確認。390×844と375×667の画面サイズでも確認。実機iPhoneでの長時間動作とSafari固有の音声・ホーム画面インストールは別途実機検証が必要です。
