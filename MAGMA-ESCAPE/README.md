# MAGMA ESCAPE

マグマ・エスケープ・アスレチック。生成した3D風アートを使った、縦画面の2Dサバイバルゲームです。

## 遊ぶ

このフォルダで `npm start`、または `node server.mjs` を実行し、<http://localhost:4188> を開きます。Macでは `ゲームを起動.command` をダブルクリックして起動できます。依存パッケージのインストールやビルドは不要です。

| 操作 | パソコン | スマートフォン |
|---|---|---|
| 左右移動 | ← → / A D | 左下の ‹ › |
| ジャンプ | Space / ↑ / W | JUMP |
| ジェット | E / Shift 長押し | JET 長押し |
| 一時停止 | Esc | 左上の Ⅱ |

足場は1mごと。ジャンプボタンは長押しで着地後に連続ジャンプ、空中で押し直すと二段ジャンプします。左右の壁に寄せてJUMPで壁キック。壁へ移動を押し続けると壁滑りで落下が緩やかになります。同じ壁からの再キックは着地か反対側の壁への接触で回復。ジェット燃料は足場に立つと回復します。

## 2.1の改善

- マグマ基本速度は22px/sから、高度とプレイ時間に応じて加速（基本速度上限96px/s）。以前の10〜24px/sから引き上げ
- 14秒以降は通常7秒→予告3秒→噴き上がり6秒（1.8倍）→小休止10秒（0.65倍）。HUDに予告・状態・実際の速度を表示
- 引き離すと滑らかに追い上げる。以前の高度に合わせた瞬間的な底上げは廃止。イベント中は停止し、再開後0.8秒は速度を抑える
- 二段ジャンプは空中での押し直しのみ。長押しで勝手に二段目を消費しない。着地で回復
- 壁キックは上向き・反対側への反発と0.2秒の方向保持。空中ジャンプも回復。左右の壁を明示し、残り空中ジャンプを表示
- 足場はリズム区間・近い足場をつなぐ連続ジャンプ区間・横移動区間・幅広い休憩区間で変化
- クイズは紫の「？」オーブ、バトルはゴーレムへの接触時に開始。高さによる自動開始・後からの割り込みを廃止。避けて通過でき、触れた対象は一度だけ消費
- 対象が画面に表示されて0.4秒経つまで接触イベントを発火しない。生成・表示・当たり判定は同じ位置を参照

## 実装済み

- 上昇するマグマ、無限の足場生成、通常・移動・点滅・崩壊の4種の足場
- 0〜50m、51〜100m、101m以降の難易度変化。崩壊は通常0.5秒、上級0.36秒
- ジェット、空腹、体力、コイン回収、追従カメラ、着地・獲得エフェクト
- 15mから約15m間隔のショップ（着地時に発生）、おにぎり・マグマ肉
- 12mから配置されるクイズオーブ、22mから配置されるゴーレム。接触すると制限時間付きクイズ／タイミングバトル
- 移動速度・ジェット飛行時間の5段階の永続強化
- コインガチャ、5種のオーラ、確率表示、重複還元、装備・コレクション
- リトライ、リザルト、記録保存、効果音と簡易BGM、音量ON/OFF、演出軽減
- キーボードと複数ポインターによる左右＋ジャンプの同時操作
- ウィンドウのフォーカス喪失・バックグラウンド移行時の自動停止
- PWA manifest、アイコン、Service Workerによる初回読み込み後のオフライン起動

ショップはSHOP足場への着地で発生。クイズとバトルは画面上のオーブ・敵への接触で、空中でもその場で停止して開始します。飛び越した対象を後から強制発火することはありません。ショップ・クイズ・バトル中はマグマと空腹の消費が止まります。

## データとPWA

セーブは従来と同じ `localStorage` の `magma-escape.v1`。コイン、強化、所持オーラ、装備、最高記録、設定、到達報酬、抽選履歴20件、未完了の開封結果を保存します。従来データを引き継ぎます。初回150コイン。進行中のプレイはページ再読み込みで終了しますが、ガチャ結果は復元します。ブラウザの保存データ削除で記録も消えます。アカウント、課金、オンラインランキングはありません。

本番配信はHTTPSの静的ホスティングにこのフォルダをそのまま置けます。相対パスなのでサブディレクトリにも対応します。iPhoneではSafariの共有メニューからホーム画面に追加します。LAN内のHTTPでゲームは動きますが、PWAのオフライン機能はHTTPSまたはlocalhostが必要です。

更新時は `sw.js` の `CACHE` のバージョンを変更します。更新案内の「保存して更新」で待機中の新版に切り替えます。更新UIのなかった初代キャッシュ（v1〜v5）は一度だけ自動移行し、次回の再読み込みで新版になります。プレイ中の画面を勝手に再読み込みしません。

## 構成

- `core.js`: DOMに依存しない固定タイムステップのゲームロジック、経済・セーブ正規化
- `renderer.js`: Canvas 2Dの描画、生成画像のアトラス、マグマとエフェクト
- `app.js`: 画面、入力、イベント、永続化
- `gacha-scene.js` / `gacha.css`: 開封状態機械、レア演出、5連結果、プレビュー
- `audio.js`: Web Audioによる効果音と控えめなBGM
- `animation.js`: 2×2シートのフレーム選択・Canvas再生・静止フレームの描画キャッシュ
- `assets/`: 同梱済みの生成画像25枚（うち9枚が4コマシート）、アプリアイコン2サイズ、スプライト座標
- `art-prompts-animation.json` / `art-sources-animation.json`: アニメーション用の生成プロンプトと元画像記録
- `tools/prepare-animation.mjs`: 透明度と各コマの固定座標を保って1024px WebPに変換
- `art-prompts.json` / `art-prompts-v2.json` / `art-prompts-worlds.json`: 実際の画像生成プロンプト。imagegenスキルのbuilt-in image_gen使用
- `art-sources.json` / `art-sources-v2.json`: この制作セッションの元画像パス記録
- `tools/prepare-assets.mjs` / `tools/prepare-v2.mjs`: 生成画像のWebP圧縮とアルファ境界の測定。再実行時のみsharpが必要
- `tests/core.test.mjs` / `tests/progression.test.mjs` / `tests/movement-pressure.test.mjs`: 物理、足場、経済、保存、ガチャ、到達報酬、二段ジャンプ、壁キック、加速、接触イベントのテスト
- `tests/browser.mjs`: Chromeによる画面遷移、操作、保存、オフライン、モバイル画面テスト
- `tests/gacha-browser.mjs`: 全レア度、単発・5連、プレビュー、連打、再読込復元、演出軽減、100m踏破
- `tests/update-browser.mjs`: 隔離されたテスト用URLで旧版からの移行・更新・記録維持を検証
- `tests/playthrough-browser.mjs`: 実際のキー入力で10mまで登り、コンボと報酬を獲得する通しテスト
- `tests/movement-browser.mjs`: キーとタッチの空中操作、見える対象への移動・接触、マグマ予告のブラウザ検証
- `tools/simulate.mjs`: 20シードでジャンプを続ける簡易操作シミュレーション

本体は外部CDNやランタイム依存なし。実行に使う生成画像一式は約6.9MB。画像は制作時に生成済みで、プレイ中に生成APIへの通信・課金は発生しません。2.0で8枚、2.2で9枚追加しました。

## 検証

`npm test` でロジックテストを実行します。ブラウザテストはChrome、Playwright、起動済みのローカルサーバーが必要です。`MAGMA_PLAYWRIGHT` にPlaywrightパッケージのパスを指定することもできます。

```sh
node --test tests/*.test.mjs
node tests/browser.mjs
node tests/gacha-browser.mjs
node tests/animation-browser.mjs
node tests/update-browser.mjs
node tests/playthrough-browser.mjs
node tests/movement-browser.mjs
node tools/simulate.mjs
```

Chromeでゲーム開始、短いキー入力、ポーズ、設定、強化、残高不足、ガチャ、装備、食事、クイズ、バトル、死亡、再読み込み後の保存、オフライン再起動を確認。アニメーションテストは実際のCanvasのピクセル変化、敵の状態遷移、演出軽減時の静止、オフラインの素材読み込みを検証します。390×844と375×667の画面サイズでも確認。実機iPhoneでの長時間動作とSafari固有の音声・ホーム画面インストールは別途実機検証が必要です。
