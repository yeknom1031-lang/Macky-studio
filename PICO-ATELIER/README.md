# PICO ATELIER 3D — 立体ピクロス工房

マウスで立体を自由に回して遊べる、日本語の3Dピクロス。3×3×3、4×4×4、5×5×5のオリジナル立体問題を各4問、合計12問収録。全問、3方向の手がかりだけで一意に解けることを検証済みです。

## 起動

`dist`を静的HTTPサーバーで配信します。例：`python3 -m http.server 8765 --directory dist`を実行し、http://localhost:8765 を開きます。ビルドやnpmのインストールは不要。

## 操作

- マウスをドラッグ：360度回転。ブロックの上からドラッグしても回転します。6pxを超えるドラッグではクリック操作を実行しません。
- ホイール：拡大・縮小。
- 左クリック：残す印。もう一度クリックすると印を外します。
- 右クリック：不要なブロックを削ります。必要なものを削ろうとすると、ブロックは残り、時間が減ります。
- 正面／上面／側面／リセット：決まった方向の視点。
- 輪切り：X・Y・Z方向を選び、スライダーで1層ずつ表示。0は全体表示です。隠れたブロックはクリック対象から外れます。
- キーボード：選んだブロックをZで残す、Xで削る。矢印で回転、＋／−でズーム、Pで一時停止。
- スマホ：タッチで選択中のツールを適用、スワイプで回転、2本指で拡大・縮小。

## ルール

面の数字は、その面と垂直な列で連続して残すブロックの数を表します。「1·2」なら1個のかたまりと2個のかたまりの間に、削るブロックが1個以上必要です。0の列はすべて削れます。各列の数字はX・Y・Zそれぞれの小さい座標から順に読みます。Xは左から右、Yは下から上、正面表示のZは奥から手前です。

輪切り中も数字は元の全体の列を表します。不要なブロックをすべて削るとクリア。必要なブロックの印付けは任意です。

30分制限。間違って残す・削ると初回2分、2回目4分、3回目以降8分のペナルティ。開始時の無料ヒントは中央のブロックを通る3方向の列を開きます。途中のヒントは選択ブロック（未選択なら中央）を通る3方向の列を開き、5分を使います。残り5分以下では追加ヒントを使えません。

途中の盤面とクリア記録はlocalStorageに保存。別タブへ移ると自動停止し、リロード時は一時停止した状態で再開できます。

## 2D版

以前の24問の2D版は `dist/2d.html` に残しています。右上の「2D版で遊ぶ」からアクセスできます。2Dと3Dは別の保存キーを使い、以前の2Dの途中経過・クリア記録を維持します。

## 検証・構成

`node --test tests/*.test.mjs`。

3Dの全12問を独立した候補列ソルバーで検証し、推測なしで一意に解けることを確認します。3Dの座標、行の交差、誤削除、ペナルティ、ヒント、クリア、途中再開も検証。2Dの検証31件も維持しています。

Three.jsは同じワークスペースの既存ゲームからコピーしてサイト内で配信しています。ライセンスは `dist/vendor/LICENSE.threejs.txt`。Google Fontsに接続できない場合もシステムフォントで動作します。WebGLが利用できない環境では2D版へのリンクを表示します。
