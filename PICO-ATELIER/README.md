# PICO ATELIER — ピクロス工房

ブラウザで遊べる日本語のピクロスです。オリジナル問題24問（5×5、10×10、15×15を各8問）を収録しています。

## 起動

`dist` を静的HTTPサーバーで配信してください。例：プロジェクト内で `python3 -m http.server 8765 --directory dist` を実行し、http://localhost:8765 を開きます。

## ルール

上と左の数字は、連続して塗るマスの数を順番に表します。数字のまとまりの間は1マス以上空けます。正解の塗りマスがすべて埋まるとクリア。空白に×を付けることは任意です。

制限時間30分。塗り間違いは初回2分、2回目4分、3回目以降8分のペナルティ。×印の間違いは減点しません。開始時のヒントは無料で、以後は5分を消費するヒントルーレットで縦横1列を開きます。残り5分以下では追加ヒントを使えません。

参考：[マリオのスーパーピクロスのルール](https://gcgx.games/super_picross/mario.html)。キャラクター・素材・問題は独自のものです。

## 操作と保存

- マウスは選択ツールに関係なく、左クリックで塗る、右クリックで×印。左右それぞれ直線ドラッグで連続入力。
- タッチ操作は「塗る」「×をつける」を選んで入力。×印の上で同じ×操作をすると消去。
- 矢印キーでカーソル移動、Zで塗る、Xで×印、Pで一時停止。
- 音は右上の♪ボタンで切り替え。
- 別のタブへ移ると自動停止。途中の問題とクリア記録はブラウザのlocalStorageに保存。

## 検証

`node --test tests/*.test.mjs`。全問題を行・列の候補から論理的に解けること、およびペナルティ・ヒント・クリア・再開を検証します。

HTML/CSS/JavaScriptのみ。ビルドや依存ライブラリは不要です。Google Fontsに接続できない場合もシステムフォントで動作します。
