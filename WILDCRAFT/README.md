# WILDCRAFT

森林や海、洞窟を探索して建築できる、オリジナルの3Dボクセル・サンドボックスゲームです。Minecraftの公式作品や完全互換版ではありません。

## 遊ぶ

`index.html` をブラウザで開いてください。`PLAY.command` のダブルクリックでも起動できます。ゲーム本体と3Dライブラリはローカルにあり、ネット接続なしでも動作します（Webフォントのみオンライン時に使用）。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 視点 | マウスを動かす（ドラッグ不要、感度は初期版の2倍） |
| ジャンプ / 水中で浮上 | Space |
| 走る | Shift |
| 採掘 | 左クリック長押し |
| ブロック設置 | 右クリック |
| スロット選択 | 1〜9 / ホイール |
| 持ちもの・クラフト | E |
| 食べる | Q |
| メニュー | Esc |
| 飛行切替（クリエイティブ） | F |
| 飛行中の下降 | Shift |

タッチ端末では左側の矢印で移動、画面のドラッグで視点操作、右側のボタンで採掘・設置・ジャンプできます。

## はじめてのサバイバル

1. 原木を3個以上集め、Eで原木から木材、木材から棒と作業台をクラフトします。
2. 持ちものの作業台をクリックして装備し、Eで戻って右クリックで地面に置きます。
3. 作業台の近くで木のツルハシをクラフト。持っている最も強いツルハシを自動使用します。
4. 石を集めて石のツルハシとかまどを作り、鉄鉱石と石炭から鉄インゴットを精錬します。
5. 葉から確率でりんごを入手。Qで食べると満腹度と体力を回復します。
6. 夜には敵が出現します。近距離で敵に向かって左クリックで攻撃できます。

## 実装範囲

- 96×48×96ブロックの有限世界、シード付き地形・森林・海岸・高地・地下空洞・鉱石
- チャンクごとの可視面メッシュ生成、ピクセルテクスチャ、採掘の破片
- 当たり判定・重力・落下ダメージ・水泳・クリエイティブ飛行
- ブロック採掘・建築、ホットバー、11種のクラフトレシピ、道具の採掘速度
- 作業台とかまどの近接チェック、レシピによる即時精錬
- 昼夜（1日15分）、動物、夜間の敵、体力・空腹、初心者向けクエスト
- ブラウザ内1スロットの30秒ごとの自動保存、手動保存・再開

マルチプレイ、無限地形、レッドストーン、別ディメンション、流体シミュレーション、道具の耐久度は未実装です。水は固定水位、ガラスは不透明なガラス風ブロック、松明はブロック形状で装備時に周囲を照らします。セーブはブラウザ・URLごとに保存されます。ブラウザのデータ消去で失われます。
