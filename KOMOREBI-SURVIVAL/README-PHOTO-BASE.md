# WILDLIGHT — 大自然の写真帖

移動先の地形を自動生成しながら、大自然と野生動物を撮影するローカル3Dゲームです。草原、原生林、山稜、雪山、渓谷、紅葉林、湿原を歩き、滑空して探索できます。

## 起動

**`遊ぶ.command` をダブルクリック**します。このMac内の `http://127.0.0.1:4186/` を開きます。Sites、外部CDN、外部API、ログインは使いません。同梱素材だけで動作します。Python 3とWebGL対応ブラウザが必要です。

## 移り変わる空と生き物

- 標準では**現実の12分で一日**。夜明け、昼、夕暮れ、月明かりの夜へ連続して移り変わります。「?」で一日を4分・12分・24分に変更できます。
- 雲は2層が異なる速さで流れ、形と量を変えます。晴れ→曇り→雨→晴れ間の気象前線を連続補間し、雨粒、霧、風、環境音を連動させます。日周とは異なる周期なので、毎日同じ時刻が同じ天気にはなりません。
- 月の位置、月面の模様、約29.53ゲーム日での満ち欠けを近似。月明かりが地形・木・動物を照らし、水面にも反射します。雲の多い夜は暗くなり、星も見えにくくなります。太陽と月の影は主な光源1灯を共用する軽量な近似です。
- 動物300種に昼行性・夜行性・薄明薄暮性・昼夜の活動傾向を設定。昼の蝶や猛禽、夜のフクロウ、朝夕のシカなど、活動量・歩行・休息姿勢を滑らかに変えます。飛ぶ鳥は翼と高度を同時に変えて着地・離陸します。近づくと警戒して起きます。同じ個体が時刻で突然別の種へ変身したり消滅したりする仕組みではありません。生態の完全再現ではなくゲーム上の近似です。
- 「動物図鑑」の**観察する時間帯**で昼・夕暮れ・夜明け・夜を比べられます。夜は昼の鳥の声が弱まり、森林では虫やフクロウ風の合成音に移行します。
- 時刻・経過日数・天候周期・速度・自動進行設定を保存し、再開時に引き継ぎます。旧版の時刻・写真も移行します。メニュー中・画面が非表示の間は時計と音を止め、放置時間を一気に進めません。
- 「空と時間を自動で進める」をOFFにすると時刻・雲・自動天気を固定します。探索や動物・水面の動きまで停止する機能ではありません。時刻スライダーと天気の選択は観察用プレビューです。通常は自動進行ON・天気「自然に変化」で遊べます。

時計と気象は `dist/climate.js`、空は `dist/atmosphere.js`、活動傾向は `dist/wildlife.js` に実装しています。雲は写真素材を使った空の描画で、体積雲・実測気象・天文学的に厳密な月軌道ではありません。

## 世界と生き物

- 128m単位の地形を座標から再生成。戻れば同じ地形・植生・生息種になります。
- 周囲121区画までを保持し、遠い区画を解放。近景は細かく、遠景は粗く描画します。
- 遠方では描画原点を移動し、座標による描画精度の低下を抑えます。数学的に無限なデータを保持する方式ではありません。
- **動物300種**：既存100種に、哺乳類100種・鳥類70種・爬虫類22種・両生類5種・昆虫3種を追加。名前・体格・生息地は `dist/wildlife.js` と `dist/wildlife-catalog.js` に定義しています。追加200種はそれぞれ異なる種で、単なる色違いの名称ではありません。学名付きは追加200種と既存名称を具体化した10種です。旧100種すべての分類監査を行ったわけではありません。異なる地域の動物が共存する架空の世界であり、実在する生態系の再現ではありません。
- 22種類の体の基本構造をもとに、種ごとの胴体・脚・首・耳・尾・角・嘴・翼の寸法や形、模様を変更。胴体から首・頭へ続く断面形状と滑らかな関節ウェイトで、部品のつなぎ目を抑えています。歩行は移動距離に同期し、支持脚・遊脚を分けた逆運動学と足元の地形サンプリングで接地を調整します。通常歩行、速歩、キリンなどの側対歩、待機、採食、警戒・退避、呼吸、まばたきを実装しています。
- 眼窩・瞼・虹彩・瞳孔・鼻孔・口元を追加し、顔の毛の方向に応じて質感を変更。117種の哺乳類では近距離32m以内だけ短い毛束の輪郭を描画します。一本ずつ独立した毛のシミュレーションではありません。頭蓋と鼻梁、頬、首、脚根元の連続性を修正し、鹿の角を非対称な枝分かれに、リカオンの模様を黒・茶・白の不規則な斑へ変更しています。
- 「動物図鑑 300」で全種の可動3Dモデルを選択し、ドラッグで回転、ホイールで拡大できます。和名・ID・登録済みの学名で検索し、生息地で絞り込めます。「顔を近くで見る」で顔中心の表示へ切り替えます。図鑑のプレビューは撮影実績には加算されません。
- **写実性の限界**：コードによる手続き型モデルです。300種を個別にスキャン・彫刻した写実モデル、モーションキャプチャ、筋肉・皮膚の物理シミュレーションではありません。共通する22種類の基本構造に寸法・形状・模様の差を付けており、種固有の構造・配色をすべて忠実に再現してはいません。実写と見分けがつかない品質には達していません。
- 木は地面に沿う根・連続した断面の先細りの幹・曲がった枝を持つ立体構造。実寸に応じた樹皮の凹凸と、小さな透過葉の房を使います。葉の表面の凹凸、ねじれ、透過光を近似し、細い針葉の素材を枝に沿って配置。広葉樹と針葉樹、低木、シダ、草の株、倒木を配置します。枝葉を風で揺らし、近距離の植生はインスタンス描画、遠くの樹冠はディザで低負荷な形状へ切り替えます。
- 木の配置候補を128m区画あたり70から121に増やし、区画内での間隔を確保。広葉樹の樹形を分け、針葉樹の枝を11〜14段にし、写真素材を3本の小枝の房へ合成しています。低木・シダは樹木周辺の群落として配置。95〜150mで細かな葉から写真素材を用いた遠景樹冠へ移行し、透明画像の縮小時に出る黒縁も補正しています。
- 日照方向に合わせた地面の影、空の高度による色の変化、太陽の散乱光、朝夕・夜空、雨・霧を実装。雲は写真調AI原画を空に投影し、時間帯で色を変えます。水面は視線角度で反射量が変わり、波でゆがむ雲を反射します。山は広い稜線と侵食溝を組み合わせ、岩壁の大きな地質模様と近景の細かな岩肌を別スケールで描画。斜面に応じて雪を分布させます。遠景地形は約8km四方の低詳細メッシュで補い、高さサンプルを再利用します。体積雲や物理的に厳密な大気・流体シミュレーションではありません。

## テクスチャ：1011枚

- **AI原画11枚**：内蔵画像生成ツールで生成した苔、岩、樹皮、毛並み、広葉樹の葉、松葉、林床、雲、細い毛束、トウヒの小枝、山の岩壁。`dist/assets/originals/` に保存。地面・山・空・木・動物に適用しています。旧松葉画像は素材として残し、針葉樹には新しい小枝画像を使用しています。
- **自動生成1000枚**：20種類の素材 × 50バリエーション、各128×128px。`dist/assets/textures/` に独立したPNGとして保存。個別に1000回AI生成したものではありません。
- `nature-atlas.png` は1000枚をまとめた4096×4096pxの読み込み用データです。枚数には重複計上しません。地面は環境に対応する素材群を選択します。ライブラリの全種類を常に同時表示するわけではありません。
- 全一覧は `dist/assets/texture-manifest.json`、AI原画のプロンプトは `ASSET-PROMPTS.txt`。再生成は `node tools/build-textures.mjs`。

## 音楽と音

`dist/soundscape.js` のWeb Audioによるオリジナル合成音です。ピアノ風の倍音、柔らかなパッド、低音、ベル風の旋律を8つの和音進行で重ね、残響と左右の広がりをつけています。雪山・山稜では音域が変わります。

風、水辺、雨、鳥の声、地面に応じた足音、シャッター音を重ねます。音量を別々に調整でき、マスターコンプレッサーを通します。録音した生楽器・自然音ではありません。

風と雨の音量は天候に合わせて補間します。夜はBGMを少し穏やかにし、昼鳥から夜虫・フクロウ風の音へ移行。メニューや非表示時はAudioContextを停止し、再開時の音符の集中を防ぎます。

## 撮影と保存

動物300種と風景7種を撮影図鑑に記録。画面内の位置、距離、地形や木による遮蔽を判定します。自由な風景撮影もできます。JPEGの実画面を直近24枚保存し、写真帖から拡大・ダウンロード・削除できます。既存の動物IDは維持し、以前の撮影実績を引き続き利用できます。

写真、図鑑、位置、時間帯、移動距離は同じブラウザ・同じURLに保存します。以前の島版の写真は初回に引き継ぎます。保存領域不足時は通知します。大切な写真はダウンロードしてください。複数タブで同じ保存先を同時に操作しないでください。検証用には `?profile=名前` で独立した保存先を使えます。

## 確認

1000枚の重複なし・上下左右の継ぎ目一致、7環境と300種の出現候補、121区画の保持上限、遠方への移動と復帰、座標±100万mでの原点移動を確認しています。300種のID重複なし、全種のリグ生成、18,000姿勢の有限値、最大196体の常駐上限も確認しています。ブラウザで全300種の選択と表示名の一致、和名・学名検索、生息地の絞り込み、検索0件時の処理を確認しています。全300種の動きを映像で精査したという意味ではありません。

動物・森林・独立画像評価の3担当で、実際の表示画像を見ながら複数回の評価と修正を実施しました。300種への拡張では頭蓋・首・脚の接続、鹿の角、狼の頬と鼻、針葉の密度、樹冠の黒縁を修正しています。山は丸い丘状の輪郭から連続する主稜線・支稜・浸食斜面へ変更し、遠山の岩模様を距離で弱めました。山の探訪地点は緩い斜面を選び、開けた谷側を向いて到着します。

昼夜・天候の変更では、時計の保存復帰、日付・気象周期の境界、雲・月光の連続性、動物の離着陸と活動の補間を数値検証しました。実ブラウザでは昼夜それぞれ全300種、計600回の選択と活動表示を確認。休息中に鳥の翼が頭上へ立つ問題、晴天の雲量、四角く見える雨粒を修正しました。音は合成処理・停止再開の検証であり、録音素材や聴感品質を保証するものではありません。

**実写品質には未達です。** 動物の顔・被毛・種固有の体型や模様、林床の疎密、遠景樹冠の反復、三角形に見える山頂と岩模様には課題が残ります。今回の独立評価もこの限界を確認しています。検証記録は `qa/VALIDATION.txt`、昼夜・天候の実画面は `qa/living-cycle/`、300種への拡張は `qa/expansion-300/`、旧版は `qa/realism/` と `qa/realism-v2/` に保存しています。描画速度は表示サイズ・場所・同時実行中のアプリに左右され、一定のFPSは保証しません。
