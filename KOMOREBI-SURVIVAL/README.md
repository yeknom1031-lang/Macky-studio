# KOMOREBI SURVIVAL — 自由探索

KOMOREBI-PHOTO を新しく全体コピーし、その自然描画にサバイバルを追加したローカルゲームです。
原作 KOMOREBI-PHOTO と前の試作 KOMOREBI-PHOTO-NEW は変更していません。

## 現在の構成（敵のいない探索）

通常敵・洞窟の敵・ボス・ラスボスの出現を停止しています。新規開始でも既存セーブでも敵は現れません。敵素材だった毛皮・牙・甲殻・羽根・古代の火種は旅商人から買えるため、ジェットパックなどの制作も続けられます。中央祭壇・封石台座、各地のボス遺跡、旧ボス洞窟、ボス用の大きな浮島をゲームから外しています。当たり判定・出現処理・地図・目標表示も停止しています。過去の討伐記録や持ち物はセーブ内に保持します。以下の旧ボス進行の説明は以前の仕様です。

探索洞窟は32か所です。山の上り斜面に入口を配置し、地形に開けた穴から地下へ下ります。内部は丸みと凹凸のある岩壁・天井で、蛇行・環状・分岐・連続広間などの構成があります。入口から奥へ照明が徐々に暗くなり、Esc / Tab の持ち物画面の「洞窟の明るさ」で40〜140%に調節できます。設定はセーブに含まれます。

地図に現在地と近い入口3か所の座標・距離を表示します。旧洞窟内のセーブを読み込んだ場合、持ち物や制作物を保ったまま旧地点の地表へ戻します。旧洞窟の配置に関する下記の過去の記録は更新前の仕様です。

`dist/underground-check.html?qa=1&profile=underground-check` は独立した検証用セーブ領域で32入口の往復と描画を確認します。`tools/test-underground.cjs` は地下への埋まり方・当たり判定・岩面メッシュを検証します。

## 起動

このフォルダの `遊ぶ.command` をダブルクリックしてください。
または `python3 launch.py`。ブラウザの http://127.0.0.1:4197/ で遊べます。
ネットへの公開や Sites の利用はありません。画像もライブラリもローカルです。

## 遊び方

- WASD 移動、Shift 走る、Space ジャンプ。冒険開始時にポインターが消え、マウスを動かすだけで見回せます。Esc でポーズメニュー。「冒険に戻る」で再開。持ち物画面ではポインターが戻り、閉じると視点操作へ戻ります。
- E 採取・調べる、Tab 持ち物、M 地図。
- 新しい冒険は持ち物・所持金ゼロ、素手で開始します。地面の木材2個と石2個を集め、最初のハンマーだけは素手で4秒かけて組み立てます。完成すると自動で手に持ち、その後の制作に使えます。既存セーブの持ち物は維持します。
- 持ち物を選んで5つの手持ち枠へ登録。ドラッグでも登録でき、数字キー1〜5で選びます。武器以外に素材・食べ物も登録できます。5枠と選択位置はセーブされます。
- 左クリック 通常攻撃、右長押しして放す ため攻撃、Q 回避、F 盾。
- 同じ場所へ材料を置く → 材料の山を E → レシピを選ぶ → ハンマーで左クリック長押し。
- 制作手帳から必要材料をまとめて置くこともできます。家は120秒で完成し、中断・再開できます。平地に建ててください。
- 焚き火を作り、木材1個で点火。復活地点になり、20枠の手動セーブを使えます。
- 敵の落とした素材は中央のお店で売れます。食べ物で体力を回復できます。
- ジェットパックを制作して背中に装備、燃料を制作して使用。Space で噴射、満タンから約7秒で空になります。R で予備燃料を使えます。
- 森・砂漠・密林・晶窟・浮島の守護者を倒し、落ちた封石を拾って中央の祭壇へ。5個全部をはめて最後の王を呼び出し、王の心石を拾って祭壇に置くとクリアです。

## 内容

11種類の攻撃用アイテム、24種の地域固有の敵、5体の守護者と最後の王、地面での制作、建築、収納箱、売買、死亡時の荷物回収、20セーブ枠、短時間のジェット飛行を実装しています。

原作の地形・森林・岩・水面・雲・昼夜・天候・300種の野生動物の実装と画像を継承しています。中心部にサバイバル用の地物を追加し、遠方へも歩いて探索できます。写真機能はゲーム画面から外しています。

初回の作り直しで64枚の画像を生成しました：アイテム38、立体物用素材14、ボス図鑑6、地域の挿絵6。継承した画像やプログラムで作った派生画像をこの枚数に含めていません。ボス・地域の挿絵は手帳用のイラストで、ゲーム画面のスクリーンショットではありません。

## 希少ダンジョンと設計図（2026-10-25）
