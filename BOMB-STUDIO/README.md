# BOMB! STUDIO

爆弾バトル、ステージ作成、キャラクター作成を楽しめる日本語のブラウザーゲームです。外部素材・ライブラリ・通信は使いません。

## 遊び方

`index.html` をブラウザーで開き、「バトルスタート」を押します。

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD |
| 爆弾を置く | Space |
| パクたまが爆弾を食べる | E / 画面の「ぱくっ！」 |
| 一時停止 / 再開 | Esc / P |

スマートフォンでは画面下の方向ボタンと爆弾ボタンを使えます。音は右上の ♪ でオンにできます。

3人のCPUを全員倒すと勝利。ライフは3、制限時間は150秒。爆弾は約2.3秒で爆発し、自分にも当たります。ブロックを壊すと、爆風・爆弾数・速度・ライフのアイテムが出ることがあります。

## 武器とたまご

- **まんまるボム**：十字の爆風。壁や最初のブロックで止まります。
- **ヨコヨコボム**：置いた場所の**横一列すべて**が爆発。途中の壁の先まで届き、その列のブロックを壊します。
- **タテタテボム**：置いた場所の**縦一列すべて**が爆発。途中の壁の先まで届き、その列のブロックを壊します。
- **ドリルボム**：範囲内のブロックを貫通。石の壁で止まります。
- **パクたま**：同じ行または列の、壁にさえぎられていない2マス以内の爆弾を食べて、横一列に反撃。たまご自身の爆風はプレイヤーに当たりません。ただし誘爆した通常の爆弾には注意。再使用まで7秒。
- **まもたま**：12秒に1回、爆風を自動で防ぎます。
- **ピョンたま**：移動が速くなります。

石の壁はどの武器でも残ります。一列ボムは壁を越えるので、別の列に逃げてください。武器とたまごはバトル前に選びます。

## つくる

**ステージ**：横7〜31マス・縦7〜25マスを指定して「この大きさにする」でサイズを変更できます（外側の壁も含みます）。サイズ変更は描いた範囲をできるだけ残し、はみ出たスタートを内側へ移動します。「もどす」で変更前に戻せます。タイルを選んでクリック・ドラッグ。プレイヤー1人とCPU1〜3人を配置し、「保存してあそぶ」。ライバルまでつながる道と、最初の爆弾からの逃げ道を確認して保存します。12ステージまで保存でき、読み込み・修正・削除・操作の取り消しに対応しています。

**キャラクター**：名前・3か所の色・アクセサリーを変更。16×16のドット絵で自分で描くこともできます。16人まで保存可能です。

保存先は同じブラウザーのローカルストレージです。ブラウザーのデータを消すと保存も消えます。別のブラウザーや、直接ファイルを開いた場合とローカルサーバーの場合では保存先が異なります。

## 開発・確認

ビルドは不要です。Node.js がある環境で `node --test engine.test.cjs` を実行すると、爆風の範囲、誘爆、たまご、ダメージ、勝敗、ステージ検証などのテストが動きます。

`engine.js` がゲームルール、`app.js` が描画と操作、`style.css` がレイアウトです。
