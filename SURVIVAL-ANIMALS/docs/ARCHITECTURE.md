# 技術構成

## 実行

ビルド工程・外部CDN・npm実行時依存はありません。静的ファイルを `server.mjs` で127.0.0.1:4177に配信します。`SURVIVAL_PORT`でポートを変更できますが、ブラウザ保存はポートごとに別扱いです。

## モジュール

| ファイル | 責務 |
| --- | --- |
| `src/data.js` | 島、モンスター、アイテム、レシピ、建築、クエスト、地形高 |
| `src/core.js` | 描画に依存しないゲーム状態、AI、戦闘、採集、捕獲、育成、移動、セーブ検証 |
| `src/view.js` | Three.jsによる地形、海、空、影、モデル、アニメーション、エフェクト |
| `src/main.js` | 入力、HUD、メニュー、音の呼び出し、保存・復元、ゲームループ |
| `src/audio.js` | Web Audioで生成する効果音と簡単な環境音楽 |
| `index.html` / `style.css` | 日本語UIと各画面のレイアウト |

毎フレームの時間差を最大0.05秒に制限し、メニュー・非表示・フォーカス喪失でシミュレーションを停止します。HUD更新は約12.5Hz。樹木・岩・草はインスタンス描画し、主役を隠す樹木の部分をディザ透過します。品質設定で解像度倍率と影を調整します。

地形の高さはシミュレーションと描画で同じ関数を使用します。海はGPUシェーダー、主人公と遺跡と装飾はプロシージャルメッシュ、動物はスキンアニメーション付きglTFです。

## データと保存

スキーマバージョン1。`localStorage`に通常セーブと直前のバックアップを保持します。所持品、建築、仲間、解放状態、時間、設定を保存。野生動物の戦闘途中の体力や座標は保存せず、未捕獲の個体は再開時に初期状態に戻ります。捕獲中に保存した場合、その保存スナップショットでは使用中のルーン石を戻します。

読み込み時はアイテム数・座標・バージョン・建築位置・種別などを検証し、未知のキーは採用しません。輸入したデータを画面HTMLとして解釈しない設計です。ゲーム内の名前は固定データから表示します。

## テスト

ゲームロジック：Node標準の `node:test`。ブラウザ：PlaywrightからChromeを実行し、キーボード・ボタンを使用。長距離移動のみ検証窓口で短縮し、採集・支払い・戦闘・捕獲・島移動・セーブ管理は実処理を通します。ブラウザテストの通信先はローカルホストに制限します。

## 配布

`assets/runtime`、`assets/licenses`、`vendor`、`src`、`index.html`、`style.css`、起動用ファイル、説明書で動作します。`concept-art`、生素材のダウンロード、`.cache`、`test-results`はゲーム実行に不要です。エンジンMITライセンスを `vendor/THREE-LICENSE.txt` に同梱しています。
