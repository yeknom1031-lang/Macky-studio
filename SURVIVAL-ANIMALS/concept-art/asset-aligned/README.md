# Asset-aligned visual target

These three screens replace the original high-detail visual target for the first playable build. They deliberately retain the faceted geometry, modular cliffs, simple vegetation, survival props, and animated animal bases available in the project's free CC0 asset library.

## Shared generation direction

- Attainable Three.js gameplay screenshot rather than cinematic key art.
- Kenney Nature Kit geometry and palette for the environment.
- Kenney Survival Kit geometry for camps, tools, storage, and construction.
- Quaternius animated animals as the base silhouettes for Emberfox, Leafhorn, moss creatures, and nocturnal enemies.
- Low-poly geometry enhanced by lighting, fog, water, particles, emissive markings, color grading, camera composition, and a consistent HUD.
- Deep-navy translucent UI with turquoise system accents and orange action accents.

## Screens

1. `01-day-exploration-combat.png` — core exploration, gathering, dodge combat, and companion commands.
2. `02-base-creature-care.png` — modular base building, feeding, comfort, storage, and farming.
3. `03-night-capture.png` — bait selection, creature state, capture probability, and night atmosphere.

## Implementation priority

The first build should match the color hierarchy, camera distance, silhouette readability, and UI density of these images. Exact geometry can differ as long as it remains within the downloaded asset library and the same low-poly visual language.
