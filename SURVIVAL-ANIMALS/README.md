# どうぶつと しまのたび — SURVIVAL ANIMALS

無料素材とThree.jsで制作した、日本語のPC向け3Dサバイバルアクションです。6つの島・9種の動物・3つの洞窟を探索できます。洞窟の奥には捕獲できる巨大ボスがいます。画面の日本語は、ひらがなと小学3年生までの漢字にしました（キー名・数字・記号を除く）。

## 新しいしまへ 行こう

**Mを おして、ちずを ひらこう。行きたい しまを おしてね。**

- 「いわのしま」には、いわの大うし。
- 「きのこのしま」には、森の大しか。
- 「火のしま」には、火の大きつね。
- どうくつの 入り口で Eを おそう。おくには 大きな ぼすが いるよ。
- ふねは、はじめから もっているよ。前の きろくにも ふねが ふえるよ。
- 「あらしのしま」は、空のくらを 作ってから 行けるよ。

## 遊び方

Macでは **`PLAY.command` をダブルクリック**してください。起動用のターミナルは遊んでいる間、開いたままにします。

ブラウザが自動で開かない場合は <http://127.0.0.1:4177> を開いてください。ゲーム内の「新しいたび」から開始できます。操作の案内は「せってい・あそびかた」にあります。

初回は浜辺のみなに近づいて **E**。次に火のこぎつねを **J** で弱らせ、**Q** で仲間にします。左上の案内が次の目標です。

| 操作                       | キー                  |
| -------------------------- | --------------------- |
| 移動 / 走る                | WASD / Shift          |
| 見回す                     | ↑↓←→ / 右ドラッグ     |
| カメラ距離                 | ホイール              |
| 攻撃 / 回避                | 左クリック・J / Space |
| 不意打ちの準備             | Cを長押ししてしゃがむ |
| 話す・採集・施設利用       | E                     |
| 捕獲 / 仲間の技            | Q / F                 |
| 騎乗・降りる               | R                     |
| 食べる / 仲間にごはん      | 1 / 2                 |
| バッグ・製作 / 建築 / 海図 | Tab / B / M           |
| ポーズ・閉じる             | Esc                   |

## 冒険のヒント

- 捕獲は体力35%以下、最終ボスと洞窟ボスは20%以下。「なかまの石」が必要です。倒し切っても捕獲できます。
- 赤い地面の予告を見たら、Spaceで範囲の外へ。捕獲中に近くから離れるとキャンセルされ、ルーン石は戻ります。
- 捕獲や戦闘で毛束を入手できます。防寒マントとサドルの材料です。
- 採集資源は毎日復活します。焚き火のそばでEを押して朝まで休むと、仲間も全回復します。
- 建築はBで設計図を選び、緑色の場所でE。置けない場合は木や建物から離れてください。
- 船は最初から所持し、海上で自動乗船します。Mの地図から別の島に直接移動できます。
- 「こおりのしか」を捕獲すると「空のくら」が解放され、「あらしのしま」へ進めます。飛行中の攻撃・捕獲はできないため、戦闘前にRで降りましょう。
- 救助されても仲間・装備・建物は失われません。資源の一部を失って浜辺へ戻ります。

## セーブ

25秒間隔と重要な進行時に自動保存します。手動保存も可能です。ブラウザ内の保存領域を使用するため、**同じブラウザ・同じURL**で「たびをつづける」を選んでください。

「設定」または「バッグ」からJSONファイルに書き出せます。ブラウザのデータ消去・別のPCへの移動に備え、ファイルを保管してください。読み込み前には検証と確認画面が入り、破損した通常セーブは一つ前のバックアップからの復元を試みます。

## 動作環境

- PCのChromeを主な検証対象としています。WebGL2、キーボード、マウスが必要です。
- 起動サーバーにはNode.js 20以降が必要です。このMacではCodex同梱のNode.jsも自動検出します。
- 素材、Three.js、UIを同梱。起動後のゲームにインターネット接続・アカウント・有料サービスは不要です。
- 重い場合は設定の描画品質を「軽量」にしてください。スマートフォン用のタッチ操作はありません。
- 別PCでは `node server.mjs` または `npm start` で起動できます。依存パッケージのインストールは不要です。

### 開発用テスト

```sh
node --test tests/core.test.mjs tests/readability.test.mjs
node server.mjs
# 別ターミナルで実施。PlaywrightとChromeのパスは環境変数で指定できます。
node tests/browser-smoke.mjs --full
node tests/browser-smoke.mjs --caves
```

`PLAYWRIGHT_MODULE`：インストール済みPlaywrightへのパス、`CHROME_PATH`：Chrome実行ファイルへのパス。
ブラウザ検証用の操作窓口は `?qa=1` のときだけ公開されます。通常画面にはデバッグメニューを表示しません。
