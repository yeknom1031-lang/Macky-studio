# 検証記録

2026-09-28 / Godot 4.7.2 / macOS / Apple M2（24 GB）

## v1.1 更新版

**211 項目成功、失敗 0**。従来の脱出経路に加え、16 種類すべての現象を実際に生成・更新し、各現象で四方向のドアを通常の一人称レイから操作できること、中断すると演出時間が止まることを検証しました。天井の移動と安全な高さ、時計の逆回転、雨の停止、視線を外したときの回転、足音の遅延再生も個別に確認しています。

現象の順番に 1 周内の重複がないこと、扉のプレビューでは順番を消費しないこと、観測記録と次の現象が保存・復元されることを確認。結果は `test-results.json` にあります。

`screenshots/v2/` は更新版を実際に描画した画面です。9 種類の区画を作成し、列柱、水鏡と雨、浮遊物、赤い裂け目、上方の装飾ドア、保全区画、天井の変化を確認しました。画像生成は表面素材の制作に使用しており、これらのスクリーンショット自体を画像生成で加工してはいません。

macOS アプリのバージョン `1.1.0`、署名の検証成功を確認しました。書き出したアプリから素材・音を読み込み、水鏡と雨の画面を `screenshots/v2/mac-water.png` に保存して終了できました。

高品質設定は Metal / Forward+、SDFGI、SSR、ReflectionProbe、薄いボリューム霧、TAA を使用します。負荷を下げるため SDFGI は 2 カスケードに調整し、ゲーム内に間接光の ON/OFF を用意しました。画面撮影はウィンドウの前後状態・強制描画・VSync 設定の影響を受け、フレーム間隔に大きな差があったため、通常プレイの FPS の保証には使っていません。

追加の描画計測：Metal の描画 CPU 時間は約 1.3〜2.1 ms でしたが、この環境では GPU 時間が 0 を返すため測定不能として記録しています。タイトルの FPS ログでは 6〜10 FPS の区間もあり、ウィンドウの状態と描画負荷を完全には切り分けられていません。比較用 Vulkan では GPU 時間を取得できましたが、パイプラインキャッシュの警告も出たため採用していません。詳細は `render-probe-metal.json` / `render-probe-vulkan.json`。高品質設定での滑らかさは未保証で、性能面には改善余地があります。

残る技術上の制約：Metal による画面撮影の正常終了時に、レンダラーが `7 RIDs of type Texture were leaked` という警告を出します。シーンと間接光を先に解放する処理を入れても残り、原因は未特定です。GDScript エラーや進行試験の失敗は出ていませんが、長時間の GPU メモリ推移は未検証です。

## ゲーム進行の自動試験

`./build-macos.command --test` で **75 項目成功、失敗 0**。
詳細は `test-results.json` を参照。

- 全 9 区画へ到達でき、36 通りの接続を逆向きにたどると戻れる。
- 実際のプレイヤーの衝突判定で、閉じたドアを通り抜けられない。
- 通常の一人称レイでドア、観測器、保全キー、出口を検出できる。
- 実際の移動処理でドアを往復し、隣の区画へ移動できる。
- 同時に 2 つ目のドアを開けられず、1 秒後には開いたドアが閉じる。
- ドアの境界で中断しても、プレイヤーが挟まらない。
- 3 つの観測値を記録し、誤った暗号から再試行できる。
- キーパッドのボタンにフォーカスがある状態でも、数字・Backspace・Enter の通常入力が通る。
- 暗号 → 実物の鍵の取得 → 回路の順序 → 隠し出口、という進行条件が守られる。
- 実ファイルへ保存し、状態を読み戻せる。主ファイル破損時はバックアップを読める。
- 隠し出口を歩いて通過するとエンディングへ進む。

試験は区画間の移動試験以外ではプレイヤーを検査対象の近くへ移動して実施しているため、全行程を人間が歩いた所要時間の測定ではありません。通常のプレイヤー用セーブには触れません。

## 画面確認

Metal / Forward+ で実際に描画した 1280 × 800 の画面を `screenshots/` に保存。タイトル、空の巨大区画、柱の区画、暗号盤、記録、設定を確認しています。企画用の生成画像ではなく、この実装を動かした画面です。

画面撮影時の短い計測では、柱の区画のフレーム間隔が平均約 6.95 ms、95 パーセンタイル約 11.81 ms。撮影用の強制描画を含み、通常プレイの長時間 FPS や熱による変化を保証するベンチマークではありません。

## 対応範囲

macOS 13 以降の Universal 書き出し。実機検証は Apple M2 のみ。Intel Mac と別 OS、コントローラー、任意のウルトラワイド画面は未検証です。最初のプレイ可能版として、敵のいない固定構成の 9 区画と 1 つの脱出ルートを実装しています。
