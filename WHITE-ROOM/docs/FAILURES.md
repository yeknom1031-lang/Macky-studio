# v1.4 — 間違った扉で、同じ部屋がおかしくなる

## 進路

9区画を使う有限の11段階。始まり → 3つの観測区画 → 始まりで鍵 → 4つの校正区画 → 回路区画 → 始まりの隠し出口。各組の区画順と、正しい扉の方角・刻印は新規プレイで変わります。

四方向の普通の木製ドアには、●・△・□・＋の刻印があります。左脇の「進路の記録」を E で読み、文章の条件に合う刻印を選びます。たとえば「二本の線が直角に交わる。内側を囲まない」は＋。進む扉は1つで、二つ目の段階からは↶の安全な戻り道もあります。最後の段階では通常ドアから先へ進まず、西壁の隠し扉を探します。

誤った扉を開いても遠くの新区画には進みません。同じ部屋・同じ進路段階へ戻り、危険度だけが1上がります。通過しなくても、ノブを回して開けた時点で確定します。1秒以内に扉が閉まり、異変の演出へ移ります。同時に二つのドアは開きません。

正しい扉でも、必要な観測値・鍵・回路が未完成なら開きません。この未達成は間違いに数えません。手掛かりは固定され、異変の強さによって正しい刻印が入れ替わることはありません。Hの段階式ヒントやTabの案内図で具体的な方角も確認できます。

## 危険度

| 危険度 | 演出と結果 |
| --- | --- |
| 0 | 空間・音のランダムな異変は休止。広い白い部屋の不思議な建築は残る |
| 1 | 照明が弱まり、空間と音の異変が始まる |
| 2 | 黒い影が近づいて消える |
| 3 | 実際の床スラブと視点が約72cm沈んで戻る |
| 4 | 左右の石のモニュメントが迫って離れる。次の誤った扉で死亡すると明示 |
| 5 | 黒い影／床の崩落／モニュメントの圧迫のいずれかで死亡 |

未到達の正しい段階へ実際に通過すると危険度が2下がります。正しい扉を覗くだけ、↶で戻る、同じ段階を往復するだけでは回復しません。装置の答えを試すことや、初めて解くことは危険度に影響しません。

危険度が残っていれば暗さとランダムな異変も持続。0に戻れば空間・音のランダムな異変は止まります。大きな死亡演出は危険度5だけで発生します。演出中は操作を止め、連打による追加の間違いを防ぎます。

## 死亡と再挑戦

約4.2秒の死亡演出の後に死因を表示。8秒後に最初の段階から自動再開します。「今すぐ最初からやり直す」でも再開できます。

- リセット：現在地、鍵、暗号箱、回路、校正、観測値、訪問記録、操作途中の状態、危険度、今回のルート間違い数。
- 保持：順路、扉の刻印と手掛かり、同じ謎と答え、50種類の選定、設定、死亡回数。
- 「はじめから」で別のプレイを始める場合だけ、順路・謎を再抽選し、50種類のうち20種類を入れ替える。

死のたびに正解を変えず、覚えた選択を次の挑戦で生かせる設計です。死因は影・崩落・圧迫の順に巡回し、最初の種類はシードで決まります。

Escやアプリ切り替えで演出・再開までの時間も止まります。危険度は扉を開いた時点で保存。閉まる前に終了して再開しても、非致命的なら同じ警告、致命的なら死亡画面に戻ります。

## 保存と検証

古いセーブは取得済みの進行を保持し、現在の区画に相当する順路の段階へ移行します。v1.1以前の固定暗号472と校正不要の条件も維持。v1.3の危険度・死亡履歴は引き継ぎます。

`route_rules.gd` が有限の接続と判定、`failure_rules.gd` が危険度、`failure_sequence.gd` が影・床・圧迫を扱います。`tests/failure_progression.gd` では多数のシード、実際のドア通過、戻り道、回復、保存、3死因、同じ順路での再挑戦、全順路からの脱出を検証します。

新規画像生成は使用していません。既存の表面素材と、実際の3D形状・シェーダーによる演出です。
