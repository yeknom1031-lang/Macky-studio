# v1.3 — 誤答が部屋を変え、死から学ぶ

## ルール

危険度は0から開始。答えを確定して誤ると1上がり、観測器・暗号盤・最終回路のいずれかを初めて正しく解き終えると2下がります。下限0、上限5。危険度5で死亡します。

| 危険度 | 演出と結果 |
| --- | --- |
| 1 | 照明が暗くなる。誤答が部屋に蓄積することを知らせる |
| 2 | 黒い影が近づいて消える。まだ生きている |
| 3 | 実際の床スラブと視点が約72cm沈んで戻る |
| 4 | 左右から巨大な石のモニュメントが迫り、止まって離れる。「次の誤答で死亡」と明示 |
| 5 | 黒い影に飲まれる／床が崩落する／モニュメントに押し潰される、の3演出から1つで死亡 |

暗さは部屋を移動しても持続し、正解で回復します。通常のランダムな40種類の空間現象は、それだけでは死亡させません。誤答に応じた危険度が死亡の条件です。

操作中の回転、選び直し、初期化、ヒントの表示は自由。未選択の回答、未完成の順序、足りない桁、観測記録不足は誤答として数えません。最終回路は接点を押した時点で接続するため、間違った接点を押すと誤答になります。正しい接点を途中まで押すだけでは危険度は下がりません。

誤答後は1.4〜3秒の前兆を一人称で見てから、同じ装置の操作へ戻ります。その間の連打を追加の誤答には数えません。危険度とルールはHUD、各操作画面、観測記録に表示します。ヒントは従来どおり最後に具体的な答えまで確認できます。

## 死亡と再挑戦

5段階目では約4.2秒の死亡演出の後に死因を表示。8秒後に最初の部屋から自動再開します。「今すぐ最初からやり直す」でも再開できます。

- リセット：現在地、鍵、暗号箱、最終回路、校正済み装置、観測値、訪問記録、操作途中の状態、危険度、今回の誤答数。
- 保持：同じ世界の選定、謎の系統と答え、設定、死亡回数。
- 「はじめから」で別の新規プレイを選ぶと、これまでどおり50種類のうち20種類を入れ替える。

死亡によるやり直しでは答えを再抽選しません。前の挑戦で読んだ手掛かりを覚えていれば、次の挑戦で生かせます。死亡のたびに影・崩落・圧迫の死因が順に切り替わります（最初の種類はその世界のシードで決まる）。

Escまたはアプリの切り替えで、演出も自動再開のカウントダウンも中断。死が確定した時点で保存し、演出中に終了して再開した場合も死亡画面に戻ります。演出中のドア操作、再開入力、通常の落下救済によって死亡が取り消されることはありません。

古いセーブには危険度0を補います。旧セーブの観測値や脱出条件は保持しながら、新しい誤答のルールを適用します。

## 実装と検証

- `failure_rules.gd`：危険度、正解による回復、死亡確定、死因の選定。
- `failure_sequence.gd`：一人称を維持した影の接近、床と視点の下降、モニュメントの圧迫。
- `threat_shadow.gdshader`：輪郭が揺らぐ、顔のない黒い影。
- `profile.gd`：危険度・死亡の保存、同じ謎での進行リセット。
- `tests/failure_progression.gd`：段階的な誤答、未完成入力の除外、回復、中断、保存、3死因、再挑戦、回復後の脱出。

新規画像生成は使っていません。影はシェーダー、モニュメントは3D形状、床は実際の床スラブを動かしています。音は本プロジェクトの既存のオリジナル合成音を使用。血液や欠損表現、戦闘操作はありません。
