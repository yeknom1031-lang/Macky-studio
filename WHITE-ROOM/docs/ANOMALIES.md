# v1.2について

現在は空間40種類・音20種類・謎10系統に拡張しています。[最新の種類一覧と採用ルール](RUN-VARIATIONS.md)を参照してください。以下はv1.1の16種類の記録です。

# 空間と怪奇現象（演出のネタバレ）

建築の構成は区画ごとに固定し、異常の種類は到着ごとに変えます。9 つの建築構成と 16 種類の現象を別々に組み合わせます。初回は照明の波、その後は新規ゲーム時の乱数シードに基づく順番です。扉を開けただけでは次の現象を消費せず、しきいを越えたときに確定します。1 周の 16 種類に重複はありません。

| 現象 | 実際の演出 |
| --- | --- |
| 消灯の波 | 天井の光が数秒周期で順番に弱まり、戻る |
| 降りてくる天井 | 格子状の天井が上下に最大 7 m 移動する |
| 無重力の立方体 | 白い塊が上下に漂い、ゆっくり回る |
| 高すぎる扉 | 地上 10 m の壁に木製ドアが出現する |
| 主のいない影 | 対応する物体のない大きな影が壁を横切る |
| 呼吸する壁 | 壁のパネルが位相をずらしながら前後する |
| 冷たい色温度 | 暖かい白から青白い照明に変わる |
| 室内の雨 | 天井下で雨が降り、水面が揺れる |
| 逆行する時計 | 壁の時計の長針・短針が逆回転する |
| 終わらない額縁 | 大小の枠が入れ子になって宙に続く |
| 壁の赤い裂け目 | 壁の細い赤い光が空気と壁を照らす |
| 遅れて返る反響 | 実際の足音を 0.9 秒遅らせ、別の位置から鳴らす |
| 目を離すと回る柱 | 視線を外してから戻すと宙の構造物が 90 度回転する |
| 追いかける光 | 天井のスポットライトがプレイヤーを追う |
| 宙に消える階段 | 空中で途切れた階段の各段が緩く上下する |
| 増殖する扉 | 通路にならない高さに、多数の閉じた木製ドアが現れる |

高所の装飾ドアは常に閉じています。通常の 4 枚のドアと隠し出口だけが移動に使えます。動く天井・構造物は頭上を塞がず、接触ダメージはありません。怪奇現象が手がかり、鍵、回路、部屋の接続を書き換えることはありません。

観測の記録は発生から 6 秒以降、視線や実際の音の再生などを判定して追加します。全室の照明・雨は部屋全体に起きるため、向きに関係なく記録します。レイによる遮蔽物判定までは行いません。記録数は脱出条件ではありません。

中断中は時間進行・雨・反響を停止します。再開時に続きを再生します。急速な点滅や突然の大音量は使用していません。
