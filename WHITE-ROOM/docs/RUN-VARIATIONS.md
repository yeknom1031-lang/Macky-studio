# v1.3の変更

誤答を確定すると危険度が上がり、5で死亡して進行を失います。正解で危険度を2下げられます。死亡時は同じ世界・同じ答えで最初から再挑戦します。[現行の危険と再挑戦のルール](FAILURES.md)を参照してください。以下の50種類の選定と脱出経路は維持されています。

# v1.2 — 50種類の探索と20種類の入れ替え

「新しくプレイするたびに約20種類が切り替わる」という解釈で実装。部屋を移動するたびには、今回採用された種類から空間現象と音の組み合わせが変わります。

## 採用される数

| 分類 | 全体 | 1プレイで採用 | 次の新規プレイで入れ替わる数 |
| --- | ---: | ---: | ---: |
| 空間現象 | 40 | 30 | 10 |
| 音・足音・残響 | 20 | 12 | 8 |
| 操作する謎の系統 | 10 | 8 | 2 |
| 合計 | 70 | 50 | 20 |

種類は分類をまたいで重複カウントしません。色違いや配置の違いを別の謎として数えていません。以前提案した100個のアイデアすべてを実装したものではなく、今回の遊びの流れに合わせた10系統の操作式パズルです。

新規プレイでは、前回不採用だった20種類すべてと、前回から残す30種類を採用。最初のプレイは全体から抽選します。音は12回、空間は30回の入室で一巡し、一巡するまでは同じ分類内で重複しません。扉を開いて覗くだけでは抽選は進まず、実際の通過で進みます。

50種類はその回に登場できる種類数です。全種類の観測や30回の移動を強制しません。脱出までの道順によって、遭遇する種類数は変わります。収集したい場合は最後の扉を通る前に探索を続けられます。

## 遊びの流れ

1. 白い9区画を探索する。四方の通常の木の扉がループ状につながる。
2. 00以外の8区画で、それぞれ異なる系統の観測器を操作する。
3. 01 / ○、03 / △、04 / □ の校正で数字を得る。数字も新規プレイごとに変わる。
4. 00北壁の暗号箱に ○ → △ → □ の数字を入力し、箱の下の実物のキーを取る。
5. 8台のうち6台を校正する。残り2台は任意。
6. 02 / ◇ の回路にキーを使い、○ → □ → △ の順につなぐ。
7. 00の西壁に現れた隠し扉を開けて歩いて通過し、エンディング。

校正の順番に制約はありません。観測器に閉じ込めたり、死亡に至るまでは、間違いで手掛かりや鍵が消えることはありません。各観測器には説明、操作の初期化、2段階のヒントがあります。2段階目で操作の答えを確認できます。

Tab → 区画の案内図で現在地、訪問済み、校正済み、次の目的地への最短の扉順を確認できます。謎の途中の操作、ヒント段階、採用された種類、次の現象は保存されます。「続きから」では再抽選しません。

## 謎の10系統

| 系統 | 実際の操作と規則 |
| --- | --- |
| 連動する照明 | 接続表を読み、隣接する灯りを反転する5スイッチで目標の点灯を作る |
| 回転する流路 | 3つの流路を90度ずつ回し、各入口に対して右折した出口を合わせる |
| 三つの分銅 | 6個から3個を選び、合計を基準重量に合わせる |
| 二進の保全信号 | 8・4・2・1の端子を選び、要求値を表す |
| 止まった時計の順序 | 4台の針と数字を読み、時刻順に入力する |
| 記号の計算 | ○・△・□の関係から値を計算し、回答を選ぶ |
| 観測座標 | 北が上の3×3図で、指定された移動の到着点を選ぶ |

| 抵抗の経路 | 全4端子を通り、指定された合計抵抗になる分岐のない3本の配線を選ぶ |

## 空間現象40種類

01〜16はv1.1から継続：消灯の波、降りてくる天井、無重力の立方体、高すぎる扉、主のいない影、呼吸する壁、冷たい色温度、室内の雨、逆行する時計、終わらない額縁、壁の赤い裂け目、遅れて返る反響、目を離すと回る柱、追いかける光、宙に消える階段、増殖する扉。

17〜40で追加：光の振り子、水平線のない窓、宙に浮く薄板、天井の波紋、白い機械の回転、壁を登る目盛り、一本だけ傾く柱、冷光の格子、近づく環、奥行きのある壁、凍結した雨粒、折り返す壁板、回る天井の羽根、接地しない柱、光の水位、反転した家具、粒子の上昇、遠い四角い太陽、畳まれる額縁、壁の波打つ継ぎ目、沈黙する照明、流れる床の線、空中の白い環、ずれる三つの時計。

追加された大きな可動形状は高所に配置。低い床の線は衝突を持ちません。どの現象も通常のドア、観測器、暗号盤、鍵、回路、隠し出口の条件を変更しません。

## 音20種類

遠い金属の余韻／圧力の抜ける入口／水滴の列／低い空洞の共鳴／天井の細い唸り／配管を流れる水／二重に鳴るラッチ／濡れた足音／布に吸われる足音／硬い床の高い反響／壁から壁へ移る風／ゆっくり脈打つ換気／床下の振動／氷のような軋み／電気接点の連なり／遠方の排水／戻ってくる入室音／高音だけが消えた空気／揺れる調律音／回転する通気口。

`tools_generate_variations.py` によるオリジナル合成音20ファイル。波形・音の立ち上がり・時間変化が異なります。足音3種は歩いた時だけ再生し、それ以外は入室時と必要に応じた間隔再生。風と通気口は音源位置も動きます。人声や敵の気配を装う音、突然の大音量は使っていません。

今回の新規画像生成は0枚。既存の生成素材2枚を継続使用し、追加工数は空間内の形状・動き・音・操作に使っています。

## 互換性と実装

v1.1以前のセーブは旧来の観測値と脱出条件のまま続行できます。新しい8台の校正を遊ぶには「はじめから」を選びます。既存の記録は日時付きで退避されます。

- `run_catalog.gd`：50種類の選定、20種類の交代。
- `anomaly_catalog.gd`：物理的な部屋移動で現象と音を進める。
- `spatial_variations.gd`：追加24種類の実際の3D演出。
- `puzzle_catalog.gd` / `puzzle_view.gd` / `station_ui.gd`：謎の生成、描画、操作、検証。
- `profile.gd`：進行・操作・選定の保存、JSON数値の正規化。

描画性能についてはv1.1からの課題が残ります。今回も60 FPSを保証していません。無数の部屋を常駐させず、現在の部屋と開いたドアの先だけを生成します。
