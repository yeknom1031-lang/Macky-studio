# v1.3で追加された危険

誤答の確定で危険度が1上がり、正解で2下がります。5で死亡し、鍵・校正などの進行を失って最初からになります。4になったら次の誤答は致命的です。観測器のヒントを2段階目まで確認してから確定してください。選び直し・初期化・ヒントでは危険度は増えません。

死亡による再挑戦では同じ答えが残るため、学んだ手順を生かせます。[詳しいルール](FAILURES.md)。

# v1.2の攻略

新規プレイでは区画01・03・04の観測器を校正し、○・△・□の数字を記録します。数字はプレイごとに変わるため、472固定ではありません。各装置のヒントを2回押すと、具体的な操作の答えが分かります。

00北壁へ3桁を入力して実物のキーを取得し、8台中6台を校正。02 / ◇の回路で○→□→△を押し、00西壁の中央ドアより北12mに現れる扉を歩いて通過してください。Tabの案内図が次の目的地への扉順を示します。

詳しくは[今回の遊びの流れ](RUN-VARIATIONS.md)。以下は旧セーブを続行する場合の攻略です。

# 攻略（ネタバレ）

上中央の方角表示と、扉の脇の記号を使います。部屋の接続は固定です。同じ扉を逆向きに通れば、元の区画に戻れます。

1. 最初の区画の北壁、中央の木製ドアの左側にある保全記録を E で読む。
2. 最初の区画から東へ進むと ○。中央付近の観測器を調べ、**○ = 4** を記録する。
3. 西へ戻り、南へ進むと △。観測器で **△ = 7** を記録する。
4. 東へ進むと □。観測器で **□ = 2** を記録する。
5. 西 → 北と戻り、始まりの区画の北壁の暗号盤へ **472** を入力する。
6. 暗号盤の下に現れた保全キーを E で取る。
7. 始まりの区画から東 → 東へ進み、◇ の区画へ。北壁の回路盤を調べる。
8. 保全キーで回路盤が開く。**○ → □ → △** の順で押す。
9. 西 → 西で始まりの区画に戻る。
10. 西壁を調べる。中央の通常のドアから北側へ 12 m ずれた位置に現れた出口のノブを E で回し、そのまま歩いて通過する。

暗号や順番を間違えてもやり直せます。時間制限やゲームオーバーはありません。

## 接続の設計

```
        北
   ∅(0) ○(1) ◇(2)
   △(3) □(4) ∅(5)
   ∅(6) ∅(7) ∅(8)
        南
```

左右端・上下端はつながっています。数値 ID は開発用で、ゲームには表示しません。∅ の区画は複数ありますが、保全盤と出口があるのは最初の区画だけです。
