# 九九ビート大放送！

21種類のミニゲームを一つのホームから遊ぶ、九九の音声入りリズムゲーム。スマートフォン横画面が基本。iPhoneのホーム画面へ追加できるPWAです。

公開版：https://kuku-beat-festival.yeknom1031.workers.dev/

最新計画：https://kuku-beat-festival.yeknom1031.workers.dev/designs/20-minigames/release-plan

## 遊び方

1. 最初は「1〜9のだんミックス」。一つの段だけを選ぶ練習もできます。
2. 「おまかせ5ゲーム」「21ゲームをぜんぶ」、好きなゲームの単独練習（5問）から始めます。初めてのゲームでは同じ舞台を使う、点数なしの1タップ練習があります。練習はスキップでき、紹介画面からもう一度試せます。
3. 問題が出たら、下の答えを1回タップします。読み上げ中でも回答できます。「56番地へ」「8を送る」など、各ゲームに合う動作がボタンに書かれています。
4. 待つ場合は3・2・1・ポン！に合わせます。正解は100点、ぴったりなら＋50点、ナイスなら＋25点。早くても遅くても、九九が正しければ成功です。長押し・連打・別の決定操作はありません。
5. 選んだ魚がかごへ入り、選んだ番地へ荷物が届くなど、回答に応じた動作を見せます。誤答でも選んだ動作を先に見せ、正しい式へ訂正します。舞台内では釣果・完成品・仲間などが積み重なります。
6. 早く答えた場合は、問題の声と回答後2拍の動作が済むと答え合わせへ進みます。正しい九九の声と余裕を確保して次問へ移り、不要な待ち時間を減らします。
7. 結果画面の式を押すと、正しい九九をもう一度聞けます。

PCは1・2・3キーで対応する答えを1回押します。フォーカスした答えはSpace / Enterにも対応。お手本の自動プレイと最初の練習は記録に含めません。

通常出題は全段が均等になる順序で重複を避けます。カエルの同段連続、おばけの再想起、くつしたの逆順ペア、バスケの再挑戦では、学習のため関連する式を意図的に繰り返します。段を固定しても、くつしたの逆順ペアでは指定した段が右側に来る場合があります。

「きろく」には81式の最近の結果と21ゲームの星を保存。苦手な式の復習、記録のJSON書き出しに対応します。データはこのブラウザ・端末内だけに保存され、別の端末とは同期しません。書き出したJSONのゲームへの再読み込み機能はありません。

## iPhone / PWA

公開版をSafariで開き、共有 →「ホーム画面に追加」。ホームの「スマホに追加・オフライン」から全素材を端末に保存できます。保存完了を確認すると通信がない状態でも遊べます。容量は画面に実測値を表示します。端末によるデータ削除があった場合は再保存してください。

manifestのlandscape指定に加え、縦向き時は回転案内を表示。iPhoneでOSの画面回転ロックを解除する操作はゲームから行えません。切り欠きとホームインジケーターの安全域を確保しています。

プレイ中やバックグラウンドで音と進行がずれないよう、同一AudioContextを停止・再開します。一時停止中は新しい回答を受け付けず、音と表示の時計を一緒に止めます。新しいPWAバージョンを受信してもプレイ中に強制更新しません。

## ミニゲーム

ジャックポット／回転ずし／ロケット／ニンジャ／カエル／早口クイズ／ドーナツ工場／ゴリラ／トレイン／魔法のジュース／バスケ／おばけ／くつした／ヒーロービル／宇宙人の逆九九／フィッシング／宅配ロボ／タコ修理店／ドラゴン／オールスター／ほんと？うそ？九九の森。

逆九九は「7×□=56」の不足する数を答えます。森とニンジャはキャラクターの九九の主張を正誤判断し、答え合わせでは誤った式を消して正しい九九を表示・読み上げます。

## 素材と音

- 追加画像生成は800回を実行済みで、779素材・3,679コマを採用しました。21素材は検収で不採用。この固有ゲーム性の改修は既存素材を再利用し、800回を再度生成したものではありません。
- 元PNG・ジョブ・実呼び出しの記録は `assets/source-art/rich-800/`、ゲーム用WebPと採用コマの定義は `assets/runtime/rich/`。全21舞台にキャラクターの演技・背景・小道具を組み込んでいます。数字は生成画像の桁を正確な数値データから組み合わせます。
- 九九に関する音声は619本（質問81、正しい九九81、偽の主張376、逆九九の質問81）。すべてかなで読みを指定しています。別に異なる掛け声100本があります。最新の内訳・尺・ハッシュは音声manifestを参照してください。
- 偽の主張は答えの±1だけでなく前後の倍数も含め、画面の式と同じ主張音声を再生します。結果では正しい九九を先に読み上げます。
- オリジナルBGM6曲、132 BPM、32拍ループ。コードで作曲・合成した曲です。全21舞台で予告音・動作音を変えます。
- オールスターはドラムと5楽器の独立音源を使います。正解でベース→鍵盤→メロディ→ブラス→ベルが加わり、同じ音声時計に合わせて実際の演奏が厚くなります。画面の仲間と楽器も増えます。
- 通常は0〜14拍直前に1回答を受け付け、9・10・11拍でカウント、12拍をボーナス目標にします。未回答時は14拍から答え合わせ、通常24拍で次問へ。早期回答時は問題音声の実際の開始・実尺と動作を考慮して答え合わせへ進み、正答音声＋1.6秒の後の4拍境界で次問へ移ります。発話開始の遅れや音声尺に応じて終了を延ばし、声を切りません。
- 掛け声は正答音声の実尺と余白を確認してから再生し、空き時間に収まらない場合は短くするか省きます。正解・連続成功・惜しい・次へなど、実際の状況に合う台詞だけを選びます。「設定 → 掛け声100コレクション」で試聴できます。
- 音楽・九九・掛け声・効果音は独立音量。動きを控えめにする設定と±300msのタイミング補正があります。補正は加点判定だけに適用し、問題が見えた時点の回答を拒否しません。

全21本の「押す意味・合図・結果・学び」の実装対応表は [制作計画](designs/20-minigames/production-plan.html#gameplay-implementation) と [計画JSON](designs/20-minigames/production-plan.json) に記録しています。

## 開発・配信

Node.js 22以降。ゲーム実行はHTML/CSS/JS/Web Audioだけで、外部API、CDN、ログインは不要です。開発時のみWranglerを使います。

```sh
pnpm install
pnpm test
pnpm build
pnpm preview
pnpm deploy
```

`pnpm preview` はdistを4177番ポートで配信。`pnpm start` はソースのプレビュー（PWA全保存はビルド版で検証してください）。Cloudflare Workers Static Assetsの独立Worker `kuku-beat-festival` で配信します。四色オセロと同じCloudflareアカウント・Wrangler方式ですが、対戦サーバーやDurable Objectは使いません。

- `src/festival-app.js`：ホーム・進行・音と表示・保存・PWA画面
- `src/festival-core.js`：出題・採点・記録
- `src/minigames.js`：21種類の舞台・キャラクター・リズムへの反応
- `src/single-answer.js`：1回答の受付、タイミング加点、早期回答後の進行
- `src/festival-lessons.js`：21舞台の操作案内、答えラベル、練習の案内
- `src/festival-scenes-1-7.js` / `src/festival-scenes-8-14.js` / `src/festival-scenes-15-21.js`：各舞台の固有動作と結果の保持
- `src/festival-art.js`：生成数字・キャラの描画
- `src/festival-audio.js`：音声時計・音楽・発話の制御
- `scripts/build_festival.mjs`：必要素材だけ配信、ハッシュ付き一覧、25MiB上限検査
- `sw.js`：バージョンごとのキャッシュ、全保存、更新待機、Range対応
- `tests/*.test.mjs`：出題・採点・1回答・声・場面の単体回帰テスト
- `tests/festival-scenes-15-21.test.mjs`：全81式の描画、選択先、遅押し、動き軽減、正しい式への訂正、楽団の参加の検査
- `tests/pwa-release.mjs`：完成ビルドを全保存し、配信サーバーを止めてオフライン起動

ブラウザでの今回改修の確認結果は公開実装計画へ記録します。旧複数ノート方式のブラウザ検証スクリプトは過去の試作向けであり、現行方式の確認結果として扱いません。

元の7の段だけの試作は `prototype.html` に保存しています。公開ビルドには制作専用ツール、原本PNG、巨大ZIPを含めません。企画ページと軽量な画面案は同梱します。

画像素材のパック：PillowのあるPythonで `scripts/build_runtime_art.py`。音声・BGM：既存 `.tools/venv/bin/python scripts/build_festival_audio.py`。VOICEVOX Core、モデル等は制作専用でGitに含めません。詳細は各スクリプトと音声フォルダーのREADMEを参照してください。

## Safariで「ページを開けません」と出る場合

公開版の `/recover` を開き、「修復して ゲームを開く」を押します。最初に端末内の保存ページを修復してから最新版の更新を試みます。九九の記録・音量などの設定（localStorage）は消しません。最新版の取得には通信が必要です。更新処理が停止している場合は待ち続けず、保存済みのゲームを開く案内を出します。その場合はSafariを終了して開き直し、もう一度 `/recover` で更新してください。ゲーム内の「ホーム画面に追加」から素材を再保存できます。

Cloudflareの `/index.html → /` の転送履歴を持ったResponseを、そのままService Workerのナビゲーションへ返すとSafariが拒否する場合がありました。保存前および返却前に転送履歴を持たないResponseへ再構築しています。PWAのテスト配信サーバーも本番と同じ307転送を行い、更新・連続再読込・オフライン・旧版からの復旧を検査します。
