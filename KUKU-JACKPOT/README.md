# 九九ビート大放送！

21種類のミニゲームを一つのホームから遊ぶ、九九の音声入りリズムゲーム。スマートフォン横画面が基本。iPhoneのホーム画面へ追加できるPWAです。

公開版：https://kuku-beat-festival.yeknom1031.workers.dev/

最新計画：https://kuku-beat-festival.yeknom1031.workers.dev/designs/20-minigames/release-plan

## 遊び方

1. 学ぶ段（1〜9、またはミックス）を選びます。
2. 「おまかせ5ゲーム」（約2分）、「21ゲームをぜんぶ」（約12分）、好きなゲームの単独練習（5問・約1分）から始めます。
3. 九九を聞き、答えを選び、そのゲームのタップ・長押し・スワイプでアクション。正解とリズムを別々に評価します。
4. 誤答・未回答でも正しい式と九九を確認できます。結果画面の式を押すともう一度聞けます。

PCは1・2・3キーで答え、Space / Enterでアクション。長押しゲームでは押して離します。スワイプ・ドラッグのゲームにもアクションボタンの代替があります。お手本モードは自動操作で、記録に含めません。

「きろく」には81式の最近の結果と21ゲームの星を保存。苦手な式の復習、記録のJSON書き出しに対応します。データはこのブラウザ・端末内だけに保存され、別の端末とは同期しません。書き出したJSONのゲームへの再読み込み機能はありません。

## iPhone / PWA

公開版をSafariで開き、共有 →「ホーム画面に追加」。ホームの「スマホに追加・オフライン」から全素材を端末に保存できます。保存完了を確認すると通信がない状態でも遊べます。容量は画面に実測値を表示します。端末によるデータ削除があった場合は再保存してください。

manifestのlandscape指定に加え、縦向き時は回転案内を表示。iPhoneでOSの画面回転ロックを解除する操作はゲームから行えません。切り欠きとホームインジケーターの安全域を確保しています。

プレイ中やバックグラウンドで音と進行がずれないよう、同一AudioContextを停止・再開します。新しいPWAバージョンを受信してもプレイ中に強制更新しません。

## ミニゲーム

ジャックポット／回転ずし／ロケット／ニンジャ／カエル／早口クイズ／ドーナツ工場／ゴリラ／トレイン／魔法のジュース／バスケ／おばけ／くつした／ヒーロービル／宇宙人の逆九九／フィッシング／宅配ロボ／タコ修理店／ドラゴン／オールスター／ほんと？うそ？九九の森。

逆九九は「7×□=56」の不足する数を答えます。森とニンジャはキャラクターの九九の主張を正誤判断し、答え合わせでは誤った式を消して正しい九九を表示・読み上げます。

## 素材と音

- 画像生成4回で15キャラクター×3ポーズと0〜9の数字×3テーマを新規制作。生成ポーズの切り替えとプログラムで、口パク・跳ねる・主操作・喜ぶ動きを表現。
- 元PNG、プロンプト、500回上限の呼び出し記録は `assets/source-art/`。ゲーム用の透過WebPは `assets/runtime/`。
- 424音声：九九の質問81、正しい九九81、偽の主張81、逆九九の質問81、掛け声100。
- オリジナルBGM6曲、132 BPM、32拍ループ。コードで作曲・合成した曲で、既存楽曲・有料作曲サービスは使用していません。
- 同じ音声時計で1問24拍を進めます。問題を聞いてから操作、14拍で正しい九九、20拍付近の空きに短い掛け声。発話尺を測り、重なる声は再生しません。
- 正解・連続成功・惜しい・次へなど、実際の状況に合う台詞だけ選びます。「設定 → 掛け声100コレクション」で全台詞を試聴できます。
- 音楽・九九・掛け声・効果音は独立音量。動きを控えめにする設定と±300msのタイミング補正があります。

## 開発・配信

Node.js 22以降。ゲーム実行はHTML/CSS/JS/Web Audioだけで、外部API、CDN、ログインは不要です。開発時のみWranglerを使います。

```sh
pnpm install
pnpm test
pnpm build
pnpm preview
pnpm deploy
```

`pnpm preview` はdistを4177番ポートで配信。`pnpm start` はソースのプレビュー（PWA全保存はビルド版で検証してください）。Cloudflare Workers Static Assetsの独立Worker `kuku-beat-festival` で配信します。四色オセロと同じCloudflareアカウント・Wrangler方式ですが、対戦サーバーやDurable Objectは使いません。

- `src/festival-app.js`：ホーム・進行・音と表示・保存・PWA画面
- `src/festival-core.js`：出題・採点・記録
- `src/minigames.js`：21種類の入力と描画
- `src/festival-art.js`：生成数字・キャラの描画
- `src/festival-audio.js`：音声時計・音楽・発話の制御
- `scripts/build_festival.mjs`：必要素材だけ配信、ハッシュ付き一覧、25MiB上限検査
- `sw.js`：バージョンごとのキャッシュ、全保存、更新待機、Range対応
- `tests/festival-browser.mjs`：全21本の正解・誤答・未回答、63問ツアー、停止、声コレクション、表示
- `tests/pwa-release.mjs`：完成ビルドを全保存し、配信サーバーを止めてオフライン起動

元の7の段だけの試作は `prototype.html` に保存しています。公開ビルドには制作専用ツール、原本PNG、巨大ZIPを含めません。企画ページと軽量な画面案は同梱します。

## 制作を再現する

画像素材のパック：PillowのあるPythonで `scripts/build_runtime_art.py`。音声・BGM：既存 `.tools/venv/bin/python scripts/build_festival_audio.py`。VOICEVOX Core、モデル等は制作専用でGitに含めません。詳細は各スクリプトと音声フォルダーのREADMEを参照してください。

## 確認範囲

ChromeとWebKitでPWA保存・オフライン起動・明示更新を検証。九九81式、全21ゲーム固有操作、誤答保持、拍の採点、音声424本とBGM6曲の実体を自動検査しています。公開時の検証結果と最新計画は `designs/20-minigames/release-plan.json`。実機iPhoneでのSafariとホーム画面起動は、この開発環境では未確認です。
