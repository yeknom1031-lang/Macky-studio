# 九九ジャックポット

オリジナルのリズム学習ゲーム。「7の段」9問を約67秒で遊びます。

## あそぶ

Macでは **「九九ジャックポットを起動.command」をダブルクリック**すると、ブラウザで開きます。
すでに起動している場合は http://127.0.0.1:4177/ を開いてください。

1. 「いっしょに練習」または「チャレンジ」を選び、「あそぶ」。
2. 出題をきき、答えをクリック／タップ。キーボードでは `1`・`2`・`3`。
3. 「3、2、1」の次の拍で「ぴたっ！」。キーボードではスペース。
4. 正解の九九が声で流れます。一緒に言ってみましょう。

「お手本をみて覚える」は自動演奏。操作しなくても一周聴けます。
正解数とリズムは別の評価です。リズムがずれても九九が正しければ正解になります。
正しい答えを選んでいれば、停止ボタンを押しそびれても九九の正解として扱います。
結果画面の式を押すと、その九九をもう一度聴けます。

設定で音楽・音声・効果音の音量、タイミング補正、動きを控えめにする設定を変更できます。
一時停止、設定中、タブを離れたときは音声の時計ごと止まります。
記録はこのブラウザ内だけに保存します。お手本の結果は記録しません。

## 実装と素材

- ランタイムはHTML / CSS / JavaScript / Web Audio API。外部API・npm依存は不要。
- オリジナル曲 **Seven on the Floor**：144 BPM、4/4、160拍、66.667秒。
- イントロ8拍 → 16拍×9問 → エンディング8拍。
- 1問内の出題0.1拍、カウント5・6・7拍、判定基準8拍、答えの声10拍。
- 音楽、声、合図を同一AudioContext上へ事前予約。描画には出力時刻を利用。
- BGMは44.1 kHz / stereo / 16-bit WAV。MP3の開始位置の不確実さを避けて拍位置を固定。
- 音声23本はVOICEVOXで事前生成し同梱。プレイ中の音声生成・マイク・音声認識はなし。
- 背景1点、キャラクター2ポーズは画像生成で制作。原本PNGと軽量なWebPを同梱。
- 濃い日本語見出しはZen Maru Gothic Blackのサブセット。ライセンスは assets/fonts/OFL.txt。

## 音楽を高品質な音源に替えるとき

`assets/audio/jackpot-funk.mid` にメロディー／ベース／鍵盤／ブラス／ドラムのMIDI、
`assets/audio/score.json` に元の音符とドラムのパターンがあります。
DAWで音色やミックスを作り直し、**144 BPM、先頭無音なし、160拍、同じ展開・合図位置**のWAVとして書き出し、
`jackpot-funk.wav` を置き換えます。ゲームの問題データと声はそのまま使えます。
曲やテンポの構造自体を変える場合は `core.js` と `audio.js` も合わせて更新します。

今回の曲はコードで作曲・合成したオリジナル音源です。商用作曲サービスや既存楽曲は使っていません。
再現できる制作工程と、ブラウザで実際に遊べる音声入りの1本を成立させるための初版です。

## 開発・再生成

Node.js 20以降で `node server.mjs`。ローカルホストの4177番ポートで提供します。
静的ファイルなので任意の通常のWebホスティングでも動きます。`file://` での直接起動には対応しません。

```sh
node --test tests/*.test.mjs
# Playwright と Chrome がある場合の実ブラウザ検証（サーバーを別途起動）
node tests/browser.mjs
```

制作時に `.tools/` 以下へPython仮想環境、VOICEVOX Core 0.17.0、ONNX Runtime 1.23.2、
Open JTalk辞書、0.vvmモデルを導入しています。これらは制作専用でGitには含めません。
音声再生成：`.tools/venv/bin/python scripts/build_voice.py`
音楽再生成：`.tools/venv/bin/python scripts/build_music.py`
依存：VOICEVOX Core 0.17.0、numpy、scipy。書体作成はfonttoolsとbrotli。

## 確認したこと（2026-10-04）

- Nodeのテスト6件：出題の網羅性、選択肢、拍の境界、答えとリズムの独立判定、補正、押しそびれ。
- MacのChromeで1曲9問を通しプレイ：誤答、未回答、早押し、押しそびれ、一時停止・再開、連打。
- 練習、チャレンジ、お手本、声の聞き直し、履歴保存、音量設定の保存。
- 320 / 390 / 768 / 1280 / 1440px幅の表示と、Chromeのタッチエミュレーションによる選択・停止。
- WAV 24ファイルの無音・クリッピング検査、声23本が所定の拍枠内に収まること。
- ブラウザのJavaScriptエラー、素材の読み込みエラーなし。

スマートフォン実機・Safariでの実機検証はまだ行っていません。
