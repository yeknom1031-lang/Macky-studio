# わちゃわちゃタウン — それぞれの暮らしが動く街

街いっぱいに暮らす住人と動物の中から、見本と同じ相手を3分以内に探してタッチするゲームです。探している間は街だけを画面いっぱいに表示します。

## このMacで遊ぶ

**「遊ぶ.command」をダブルクリック**するとGoogle Chromeで開きます。`index.html` を直接開いても遊べます。インストール、サーバー、ネット接続は不要です。

開発用プレビュー：`http://127.0.0.1:8847/?v=diverse-open-town`。普段は起動ファイルを使ってください。

## 今回の変更

- 元の16体に、画像生成で描き分けた64体を追加。**80の基本デザイン × 4通りの色**です。
- おじいちゃん、おばあちゃん、ピエロ、青年、ぽっちゃりした人、背の高い人、様々な肌色・服装・ジェンダー表現の人、車いすの人、職人、家族、仮装、犬4種・猫4種が登場します。性的指向を外見で推測する仕組みはありません。虹の小物などを含む架空の人物デザインとして表現しています。
- 新しい住人には歩行、手振りなどのジェスチャー、各自の専用動作を用意。編み物、ジャグリング、撮影、体操、バスケ、パン作り、大工仕事、水やり、掃除、絵画、陶芸、楽器演奏、フラフープ、なわとび、赤ちゃんをあやす動作などを組み込みました。
- 犬は匂いを嗅ぐ・ボール遊び・寝転ぶ、猫は毛づくろい・飛びつく・丸まるなど、それぞれの動きをします。
- 歩く速さ、加減速、立ち止まる間隔、寄り道、引き返し方に個人差があります。行動の開始時刻と周期もずらしています。
- 雲7つ、風船24個、カモメ16羽、蝶18匹が独立して動きます。シャボン玉遊びもあります。
- 探す画面のヘッダー、時計、ボタン、イベント帯と吹き出しを非表示にしました。見本・残り時間・ヒントは一時停止中に確認できます。

## 混雑を自然に避ける仕組み

0.8秒ごとに街の混雑を調べます。近くの空いている場所を優先し、散歩中は進行方向を保ちながら混んだ道を避けます。遊びや会話を終えた住人は、混雑していれば近くの空き場所へ道に沿って歩いてから次の行動を始めます。遅い人を遠回りさせすぎない距離制限もあります。

店・釣り場・演奏会・遊び場には、向かっている人も含めた人数の目安を設けています。列や会話を途中で強制解除したり、住人を瞬間移動させたりはしません。

## ルールと操作

全7ステージを最初から選べます。どの街も開始時から**合計600体**で、動物は最大80体、人間の住人は最低520人を保ちます。全320通りの見た目が登場し、探す相手と同じ見た目は1体だけです。

制限時間は180秒。お手つきは−3秒。ヒントは−10秒で1回だけ使えます。乗り物に乗っている相手もタッチできます。一時停止中や別のアプリへの切り替え中は時計と街の動作が止まります。クリア記録はブラウザに保存します。

| 操作 | マウス・タッチ | キーボード |
| --- | --- | --- |
| つかまえる | クリック・タップ | — |
| 街を動かす | ドラッグ | 矢印キー |
| 拡大・縮小 | ホイール・ピンチ | ＋・− |
| 初期表示に戻す | — | 0 |
| 見本・残り時間・一時停止 | 2本指を動かさず長押し | Esc・P |

ブラウザが対応している場合は開始時に端末の全画面表示に入ります。非対応でも、ゲーム領域はブラウザ内を端まで満たします。縦画面ではドラッグして街の両端まで探せます。

## 画像と軽量化

今回の新素材は **built-in image_genで制作した9枚の透過アニメーションシート**です。原本とプロンプトは `assets/diversity/` に保存しています。新しい64体は、歩行・ジェスチャー・専用動作の3クリップを持ち、各5再生位置、1体あたり計15再生位置です。生成画像の実際の配列はシートによって14〜17ポーズのため、各動作の4〜6ポーズから選んで割り当て、WebGLで隣接ポーズを連続補間します。既存16体の歩行は15コマです。

- 人物本体はおおむね高さ44px、余白と持ち物を含む64×64pxのセルに格納。
- 色違いを4倍の画像として持たず、WebGL側で色を変更。基本80体分を1920×2688pxの1枚の画像にまとめます。
- 人物・乗り物・小道具をまとめて描画。画面外の描画を省略し、背景を別レイヤーにします。
- 描画は上限30fps。時計は実時間で管理します。
- HTMLは約8.8MiB。前版の約11.9MiBからさらに縮小しました。
- WebGL 2が使えない場合はCanvas 2Dで描画します。Canvas版はポーズを切り替える方式で、WebGLの補間は行いません。
- 生成PNGは保存したまま、切り出しと隣接セルの切れ端除去・縮小を行うビルドで軽量版を作ります。

新素材のプロンプト：`assets/diversity/prompts.json`、`assets/diversity/potter-prompt.txt`。背景と旧素材のプロンプト：`assets/prompts.json`、`assets/life-prompts.json`、`../output/wacha-wacha-town-20260928/README.md`。

## 開発と検証

- `src/core.js`：人数、経路、混雑を避ける進路、制限時間、タッチ判定
- `src/life.js`：行動、個人ごとの移動、混雑分布と移動先、街の出来事
- `src/render.js`：まとめ描画、ポーズ補間、色違い、環境アニメーション
- `src/app.js`：開始・一時停止・操作・結果・記録
- `measure_diversity.py`：生成シートの実配置に合わせた切り出し位置
- `build_runtime_assets.py`：切り出し、縮小、描画用画像の作成
- `build.py`：オフラインHTMLへの組み込み

```sh
python3 build.py
node --test tests/core.test.cjs tests/life.test.cjs
node tests/browser.cjs
node tests/mobile-performance.cjs
```

ビルドにはPillow・NumPy、ブラウザ検証にはPlaywright・Google Chromeを使用します。結果は `QA.md` と `test-results/` に保存しています。移動領域は2D背景から測定した道で、建物の細かな前後関係を持つ3Dマップではありません。
