# わちゃわちゃタウン — 暮らしが動く街

買い物、会話、釣り、遊び、乗り物、演奏会、警察の追跡。600人がそれぞれの時間を過ごす街から、見本と同じ住人を3分以内に見つけてタッチするゲームです。

## このMacで遊ぶ

**「遊ぶ.command」をダブルクリック**してください。Google Chromeで開きます。`index.html` をブラウザで直接開いても遊べます。

インストール、サーバー、ネット接続は不要です。約12MBのHTMLに画像とゲームを内蔵しています。開発用の一時プレビューは `http://127.0.0.1:8847/?v=living-town` です。普段は起動ファイルを使ってください。

## ルール

- 全7ステージを最初から選べます。各シーンは開始時から常に **600人**。人数を減らした練習ステージはありません。
- **320種類の見た目**。画像生成で制作した16種類の基本キャラクター × 20通りの衣装カラーです。元の200種類に、警察官・泥棒・釣り人・店員・演奏家・恐竜の仮装の子どもを追加しました。
- 全シーンに320種類が登場し、探す相手と同じ見た目は必ず1人だけです。相手と配置は毎回変わります。
- 制限時間は **180秒**。乗り物に乗っている相手も、会話や買い物をしている相手もタッチできます。
- お手つきは−3秒。ヒントは−10秒で1回。相手がいたおおよその場所を5秒間表示します。
- 一時停止や別のアプリへの切り替え中は、街の活動も時計も止まります。
- クリアした街と最速記録を、このブラウザに保存します。

## 街の暮らし

| 行動 | 起こること |
| --- | --- |
| 買い物 | 店へ向かう → 順番待ち → 店員から購入 → 袋を持って歩く → おやつを食べる |
| 会話 | 近くの住人が立ち止まり、向き合っておしゃべり。終わるとそれぞれ移動 |
| 釣り | 水辺で糸を垂らす。ときどき魚が跳ねて釣果が増え、また釣りを続ける |
| 遊び | ボールが弾む。子どもの鬼ごっこでは、接触すると追う役が交代 |
| 乗り物 | 路面電車、ボート、ティーカップ。住人が乗り、移動・周回し、降りて街に戻る |
| 演奏 | ギターの演奏、音符、観客の手拍子やダンス |
| 休憩 | ベンチで読書・休憩し、時間がたつとお出かけ |
| 配達 | 自転車で店へ荷物を運び、また次の届け先へ |
| 泥棒と警察 | バッグを持ち逃げ → 警察が道に沿って追跡 → 接触して確保 → 見回りに戻る |

画面下の「街のいま」は、実際に起きた出来事を表示します。人数・見た目・持ち物は行動が変わっても保持されます。

## 操作

| 操作 | マウス・タッチ | キーボード |
| --- | --- | --- |
| つかまえる | キャラクターをクリック・タップ | — |
| 街を見渡す | ドラッグ | 矢印キー |
| 拡大・縮小 | ホイール / ピンチ / ＋・−ボタン | ＋ / − |
| 全体表示 | 倍率ボタン | 0 |
| 一時停止 | Ⅱボタン | Esc / P |

縦画面では拡大した状態で開始します。画面外の住人も、街には常に存在しています。

## 軽量化と素材

- 人物は1コマ **40×48px**、歩行は1周期 **15コマ**。元の生成素材から足元をそろえて小さくしています。
- 320種類×15コマと小道具を、1枚の描画用画像に事前にまとめています。起動時の大量の色変換処理をなくしました。
- WebGL 2では人物・乗り物・小道具をまとめて描きます。画面外は描画を省略します。WebGL 2が使えない場合はCanvas 2Dに切り替わります。
- 背景は画像レイヤーとして表示し、毎フレームの再描画をなくしました。
- 描画は30fpsを上限にして負荷を抑えます。ゲームの制限時間は実時間で管理します。
- 背景と人物画像をWebPで圧縮。HTMLは旧約41MBから約12MBへ縮小しました。
- 元の生成PNGは編集せず `assets/` に残し、軽量版は `assets/runtime/` に保存しています。

画像はbuilt-in image_genで生成。背景のプロンプトは `assets/prompts.json`、職業キャラクターと小道具は `assets/life-prompts.json`、最初の背景・表紙は `../output/wacha-wacha-town-20260928/README.md` にあります。歩行シートAの16コマから15コマを採用し、B・Cの15コマと周期をそろえています。

## 開発と検証

- `src/core.js`：人数、移動、経路、制限時間、タッチ判定
- `src/life.js`：買い物・会話・釣り・乗り物・鬼ごっこ・警察などの行動
- `src/render.js`：まとめ描画、人物、小道具、動作・吹き出し・釣り糸、カメラ
- `src/app.js`：画面、操作、記録、一時停止
- `src/shell.html` / `src/style.css`：画面デザイン
- `build.py`：単独で動くHTMLを作成
- `build_runtime_assets.py`：小さい人物画像、色違い、軽量画像を作成
- `build_navigation.py`：背景の舗装色から通行領域を測定

```sh
python3 build.py
node --test tests/core.test.cjs tests/life.test.cjs
node tests/browser.cjs
node tests/mobile-performance.cjs
```

開発時だけPythonのPillow・NumPy、ブラウザ検証時だけPlaywright・Google Chromeが必要です。実行済みの確認結果は `QA.md` と `test-results/` にあります。

保存はブラウザのlocalStorageを使用します。保存が制限された環境でも遊べますが、次回まで記録を保持できません。移動領域は2D背景の色から測定しており、建物の細かな前後関係を持つ3Dマップではありません。
