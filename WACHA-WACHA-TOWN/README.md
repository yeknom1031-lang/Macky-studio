# わちゃわちゃタウン

街いっぱいに暮らす住人と動物の中から、見本と同じ相手を3分以内に探してタッチするゲームです。全7ステージ、全画面で遊べます。

## 遊ぶ

このMacでは「遊ぶ.command」をダブルクリックするとGoogle Chromeで開きます。`index.html` を直接開いても遊べます。インストール、サーバー、ネット接続は不要です。

開発プレビュー：<http://127.0.0.1:8847/?v=250-camera-town>

## 250種類・500体

- **250種類のベース × 異なる2色で各1体 = 500体**。全ベースが毎回登場します。同じベース・同じ色の重複はありません。
- 衣装の候補は各4通り。住人ずかんでは1,000通りを見られます。
- 既存80種類に、画像生成で描き分けた170種類を追加しました。職人、料理人、音楽家、スポーツ、工作、家族、いろいろな体格・年代・装い、仮装、車いすの人、犬・猫・うさぎ・鳥などが登場します。
- 演奏、料理、工作、買い物、会話、釣り、鬼ごっこ、警察と泥棒、配達、乗り物の乗降などが起こります。動く速さ、停止、再開、寄り道、引き返し方は人それぞれです。
- 雲7つ、風船24個、カモメ16羽、蝶18匹、シャボン玉も動きます。吹き出しは表示しません。

## 写真で探す

画面右下のカメラ、または **Cキー** で撮影範囲を出します。ポインター・タッチで範囲を動かし、もう一度カメラまたはCキーを押すと撮影します。範囲は画面面積の10％です。×またはEscで撮影を中止できます。

撮影後も街と時計は進み、**3秒後**に写真が開きます。写真は撮影した瞬間の風景で、探す相手以外の住人は写りません。撮影範囲に本人がいなければ風景だけになります。写真を閉じて街に戻り、本人をタッチしてください。写真自体をタッチしてもクリアにはなりません。

**1ゲーム3枚まで**。現像中に次の撮影はできません。一時停止中は現像も止まります。できた写真は一時停止メニューで見返せます。再挑戦すると枚数が戻ります。

## 重なり・混雑

街の密度を0.8秒ごとに調べ、散歩や用事を終えた住人は近くの空いている道を選びます。店や遊び場への集中も抑えています。

近くの2体ごとに体の重なりを測り、徐々に横へよけます。長く隠れ合う組には早めに間隔を広げる補正を行い、3秒以内に分離させます。判定は体格に合わせた胴体の楕円です。手持ちの大きな道具や飾りの先端が触れるだけの場合は含めません。乗客も判定対象です。

## 操作・ルール

制限時間180秒、お手つきは−3秒。見本・残り時間は一時停止中に確認できます。別のアプリへ切り替えると街と時計が止まります。クリア記録はブラウザに保存されます。

| 操作 | マウス・タッチ | キーボード |
| --- | --- | --- |
| つかまえる | クリック・タップ | — |
| 街を動かす | ドラッグ | 矢印キー |
| 拡大・縮小 | ホイール・ピンチ | ＋・− |
| 初期表示に戻す | — | 0 |
| 写真 | カメラ → 範囲移動 → カメラ | C → 範囲移動 → C |
| 撮影を中止 | × | Esc |
| 見本・残り時間・一時停止 | 2本指を動かさず長押し | Esc・P |

対応ブラウザでは開始時に端末の全画面表示に入ります。縦画面ではドラッグして街の両端まで探せます。探索画面の常設UIは小さなカメラボタンのみです。

## 素材・描画

今回の追加素材は **built-in image_genで生成した17枚の透過アニメーションシート**です。原本・170体の一覧・全プロンプトを `assets/expansion/` に保存しています。以前の64体は `assets/diversity/`、初期16体と背景は `assets/` に保存しています。

新170体は歩行4ポーズ＋専用動作4ポーズが基本です（フェンシングの専用動作は3ポーズ）。各クリップを5再生位置に割り当て、歩行・ジェスチャー・専用動作の計15再生位置として扱います。ジェスチャーは専用動作のポーズを共有します。実画像がすべて別の15コマという意味ではありません。旧64体は各動作4〜6ポーズから割り当て、初期16体の歩行は15コマです。

人物本体の高さを概ね44pxから60pxへ、描画用セルを64×64から80×80へ引き上げました。背景の圧縮品質も上げ、高密度画面では最大1.5倍の描画解像度を使います。ポーズの切り替え時のみ短い補間を入れ、輪郭が常に二重にならないよう調整しています。

- 重複する再生位置は同じ画像領域を共有。2,543枚の実フレームを3840×4368の画像に集約。
- 色違いはGPUで変換し、4倍の画像を保持しません。
- 人物・乗り物・小道具をまとめて描画し、画面外の描画を省略。上限30fps。
- オフラインHTMLは約18MiB。画像の種類と品質を増やしたため、前版の8.8MiBから増えています。
- WebGL 2が使えない場合はCanvas 2Dで描画します。
- 原本PNGは変更せず、ビルドで切り出し・切れ端の除去・縮小を行います。

## 開発

`src/core.js` が人数・経路・時計・写真回数、`src/life.js` が暮らし、`src/space.js` が重なり回避、`src/render.js` が描画・写真、`src/app.js` が操作を担当します。`measure_expansion.py` と `measure_diversity.py` は生成画像の実配置を読み、`build_runtime_assets.py` が描画用素材を作ります。

```sh
python3 build.py
node --test tests/core.test.cjs tests/life.test.cjs tests/spacing.test.cjs
node tests/browser.cjs
node tests/mobile-performance.cjs
```

ビルドにはPillow・NumPy、ブラウザ検証にはPlaywright・Google Chromeを使用します。結果は `QA.md` と `test-results/` に保存します。移動領域は2D背景から測定した道で、建物の細かな前後関係を持つ3Dマップではありません。
