# 全24ステージ画像制作計画の資料

[画像とアニメーション制作計画](画像制作計画.html)をブラウザーで開くと、目次、ステージ別付録、人物検索、素材検索を読めます。HTMLには台帳を埋め込んでいるため、サーバーとネット接続は不要です。印刷は本文と付録を対象とし、全件の人物・素材台帳は検索画面とJSONで提供します。

- `PLAN.md`：写真の新ルール、制作範囲、原画数量、品質基準、制作工程。
- `CATALOG.md`：24ステージの配役・場所・環境・イベント、全250役割、全96動物。
- `production-ledger.json`：全4,300人と全素材枠の制作指示。全項目は未生成。
- `catalog_source.py`：ステージと役割の編集元。
- `build_catalog.py`：台帳と付録を生成し、人数・役割・IDの整合を確認。
- `build_reader.mjs`：本文・付録・台帳を読みやすいHTMLにまとめる。Node.jsとmarkedを使用。

生成画像、ゲーム本体の変更、Godot移行はこの資料作成に含めていません。提案値とユーザー指定の条件は本文で区別しています。修正後はPythonの台帳生成、Node.jsのHTML生成の順に再実行します。
