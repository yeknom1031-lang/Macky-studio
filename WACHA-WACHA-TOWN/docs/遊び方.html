WACHA WACHA TOWN · 24の街

にぎやかな街で、
あの人を見つけよう。

見本と同じ人を、3分以内にクリック。
仕事中も、おしゃべり中も、乗り物の中も。
ひとりで探したり、ふたりでかくれんぼを楽しめます。

ゲームを開く →

まずは、ひとりで

  1. 遊びたい街を押します。モード選択はありません。
  2. 探す人を覚えたら「準備OK、はじめよう！」。3・2・1のあと、3分間の探索が始まります。
  3. 街をドラッグして移動。ホイール・ピンチで拡大できます。
  4. 見つけた人をクリックすると「みーつけた！」。お手つきは残り時間が3秒減ります。

左上の見本は、押すと大きくなります。残り時間は右上にいつも表示されます。Ⅱ・Esc・Pキーで一時停止し、撮った写真も確認できます。「街を出る」で街の一覧へ戻れます。

カメラマンを見つけよう

写真は最初0回。カメラを持った5人を見つけると、1人につき1枚、合計5枚まで撮れます。同じ人からは1回だけです。

  1. 右下のカメラ、またはCキーで撮影枠を出す。
  2. 枠の中をドラッグして撮りたい場所へ動かす。離すとその位置で固定されます。
  3. もう一度カメラ、またはCキーで撮影。
  4. 3秒後に写真が開きます。探す相手だけが写り、ほかの住人や動物は写りません。
  5. 写真を閉じて街へ戻り、本人をクリック！

撮った範囲に本人がいなければ風景だけになります。写真そのものを押してもクリアにはなりません。×かEscで撮影を中止すれば回数を使いません。

現像中・写真を見ている間も、街と時計は動き続けます。一時停止中は街も現像も止まります。

ふたりで、かくれんぼ

ひとりが探し、もうひとりが探される人を自由に動かします。3分逃げきれば、隠れる人の勝ち。

  1. Switch互換コントローラーをMacにつなぎます。
  2. ゲーム画面を一度クリックしてから、スティック・十字キー・ボタンを動かします。操作を検出すると自動で参加できます。
  3. 探す人：マウスで移動・写真・クリック。ひとり用と同じ操作です。
  4. 隠れる人：左スティック・十字キーで移動。行動ボタンで、近くの設備や乗り物を使ったり離れたりできます。

「操作する人の補助画面」は必要なときだけ開けます。1つの画面でも遊べます。補助画面を別のディスプレイへ移すと、隠れる人は自分の周りを見ながら動けます。探す人の画面は相手へ自動で追従しません。

8秒操作しないと、探される人は自動で動きます。もう一度操作すれば引き継げます。接続が外れたり補助画面を閉じたりしても、ゲームは続きます。反応がないときはゲーム画面をクリックし、「接続を確認」を押してください。行動ボタンは下・右・左・上から選べます。

ブラウザで認識できるGamepad API対応機種を使用します。Switch本体用ソフトではありません。物理コントローラーは未検証で、自動テストは模擬入力で実施しています。

音楽と街の音

街ごとに音楽が変わり、話し声、鳥、波、風、駅や工房の音が重なります。タイトル画面・一時停止の音量で大きさを調整し、音あり／音なしでミュートできます。設定は次に遊ぶときも保存されます。

音もゲームに同梱しているので、ネット接続は不要です。音楽・環境音の作者と利用条件

いつでも開くには

このMacでは、デスクトップの「わちゃわちゃタウン.app」をダブルクリック。ゲーム本体をアプリ内に保存するため、Codexを閉じたあとやMacを再起動したあとも、ネット接続なしで開けます。

24ステージ版 v2.2を収録しています。音楽と新しい街の画像もアプリに入っているため、追加のダウンロードは不要です。

動きが重いときは、タイトル画面の「空の演出を少なめにする」を選び、ほかの重いアプリやタブを閉じてください。
