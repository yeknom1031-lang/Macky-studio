# Macky Studio ゲームポータル

このMacにあるゲームを、サムネイルから選んで起動するローカルのゲーム棚です。初期登録は46タイトル（別モード・2D版を含む）。

## 開き方

デスクトップの **「Macky ゲームポータル.command」**、または Macky-studio 直下の **「ゲームポータルを開く.command」** をダブルクリックします。通常は `http://127.0.0.1:4390/` が開きます。ポートが使用中なら4391〜4399を調べます。Macの再起動後も同じファイルから起動できます。

サムネイル、タイトル、「遊ぶ」のどれからでも起動できます。ゲームはブラウザまたはMacアプリで開き、ポータルはそのまま残ります。検索、ジャンル、お気に入り、最近遊んだ一覧、おまかせ起動に対応しています。`/` キーで検索欄に移動できます。

お気に入り・起動履歴はブラウザ内に保存されます。ゲームのセーブとは独立しています。既存の専用URLが分かる作品と直接開く作品は、従来の起動先を使用します。その他はゲームごとの固定ポートを使うため、以前に別のURLで遊んだセーブは別になる場合があります。元のゲームファイルを変更・コピーする処理はありません。

## 各ゲームを直接起動

42個のゲームフォルダすべてに **「ゲームを起動.command」** と **「起動方法.txt」** を用意しています。従来の `遊ぶ.command`、`PLAY.command` なども同じ共通起動処理に統一しています。別モードは `2D版を起動.command`、`Party Fever.command`、`Abstract Rift Maker.command`、`Falling Gameを起動.command` で開けます。Godotの編集用・ビルド用コマンドは変更していません。

62個のゲーム起動コマンドを、構文検査と `--check`（ゲームを開かずに起動先を確認）で検証しました。結果は `qa/launcher-verification.json`、対象一覧は `launchers.json` に保存しています。

## ゲームの追加

Macky-studio直下のフォルダの `index.html` または `dist/index.html` を自動検出します。「一覧を更新」で再検出します。バックアップ、QA、素材、デザイン見本は対象外です。アプリ版や別モードは `catalog.py` に明示登録しています。

タイトル・ジャンル・説明は `catalog.py`、生成サムネイルは `assets/<ゲームID>.png` です。表紙と46点のサムネイルは組み込みの `image_gen` で制作したイメージイラストで、実際のプレイ画面ではありません。生成プロンプトは `image-prompts.json` に保存しています。

## ローカル起動の仕組み

Python 3の標準ライブラリだけで動作し、追加インストールやビルドは不要です。サーバーは127.0.0.1だけで待ち受けます。ポータルの起動ファイルは必要なサーバーをバックグラウンドで起動して終了します。Mac再起動後に自動常駐する設定は追加していません。

ブラウザゲームはゲームごとに配信します。使用中のポートは入口HTMLが一致する場合だけ再利用し、異なるゲームなら別のポートを選択します。Macアプリは登録されたアプリのみを `open` で起動します。起動APIは同一オリジンと起動時に発行するトークンを検査し、任意のパスやコマンドは受け付けません。`/api/prepare` は起動先の確認用で、ブラウザやアプリを開きません。

停止する場合は、このポータルの `server.py --serve` プロセスを終了します。配下のゲーム用サーバーも同時に終了します。ログは `/tmp/macky-game-portal-4390.log`（使用したポート番号）です。

Sites、外部公開、オンラインホスティングは使用していません。ポータル自体は外部通信なしで動きます。各ゲームが元々利用している外部素材等の仕様はそのままです。

## 確認

- 46タイトルの起動対象ファイルと、Macアプリの実行ファイルを確認。
- ブラウザ版すべての入口URLでHTMLの取得を確認。
- 検索・ジャンル・お気に入りの再読み込み後の保持・最近遊んだ一覧・ヘルプ・390px表示をブラウザで確認。
- PICO ATELIER、KOMOREBI SURVIVAL、雲海の航海者、つみあげラボの読み込みと画面を確認。
- PICO ATELIERの実際のブラウザ起動、MEDAL LOUNGEのMacアプリ起動と画面を確認。
- ポート競合時に別ゲームを開かないこと、起動APIの入力制限をテスト。
- 各作品の全ステージ・全操作を再検証したものではありません。

```sh
python3 -m unittest discover -s GAME-PORTAL/qa -p 'test_*.py' -v
```

`qa/browser-check.cjs` はこのMacに同梱されているPlaywrightとGoogle Chromeを利用した確認スクリプトです。`qa/verification.json` に結果、`qa/portal-desktop.png` と `qa/portal-mobile.png` に確認画像を保存しています。
