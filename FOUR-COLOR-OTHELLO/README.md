# 4色オセロ

ブラウザで、1つの画面を4人で交代して遊ぶゲームです。インターネット対戦やCPU対戦はありません。

## 遊び方

- 中央4×4に赤・青・黄・緑を各4枚配置して開始します。
- 手番は赤 → 青 → 黄 → 緑です。
- 縦・横・斜めで自分の石ではさんだ他の色の石が、自分の色になります。異なる色が混ざった列も返せます。返した石からの連鎖取りはありません。
- はさめる石のないマスには置けません。置き場所のヒントは出しません。
- 置ける場所がない人は1.5秒間の案内の後、自動でスキップします。0枚になった色も同様です。
- 全員が置けなくなるか、盤が埋まると終了。最多枚数の人が勝ち。同率一位は引き分けです。
- 4辺のトレーにある石は装飾です。予備の石の枚数による制限はありません。
- タップ・クリックで操作。キーボードは矢印キーとEnterに対応します。
- 対戦中はブラウザの「戻る」でホームに戻れます。対局の途中経過は保存しません。
- ホームの「設定」で音とアニメーションを調整できます。設定だけ端末内に保存します。

## ローカル起動

このディレクトリで以下を実行し、ブラウザで http://127.0.0.1:4187 を開きます。

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory dist
```

ES modulesを使うため、HTMLの直接ダブルクリックではなくHTTPサーバーで開いてください。

## テスト

追加パッケージなし、Node.js 22以降で実行できます。

```sh
node --test tests/engine.test.mjs
```

26項目のルールテストと500回の決定的シミュレーション（24,000手）を含みます。ブラウザで行った実機検証は `TESTING.md` を参照してください。

## 構成

- `dist/index.html` — ホーム、ゲーム画面、ルール・設定・結果のダイアログ
- `dist/style.css` — 立体的な石とボード、4辺の収納トレー、画面サイズへの対応
- `dist/engine.js` — DOMから独立した純粋なルール処理
- `dist/app.js` — 表示、操作、裏返し、パス、音、設定
- `tests/engine.test.mjs` — ルールとランダム対局の検証

フレームワーク・CDN・外部フォントに依存しない静的サイトです。対応ブラウザではWebMCPから盤面の読み取りと石を置く操作が可能です。通常のブラウザではこの機能がなくても遊べます。
