# 4色オセロ

「ひとりで遊ぶ（あなたが赤、残り3色がAI）」と「4人で遊ぶ」を選べるブラウザゲームです。

## すぐ遊ぶ

**このフォルダーの `4色オセロ.html` をダブルクリックしてください。**

HTMLの中にプログラム・見た目・音をすべて含めています。ネット接続、追加アプリ、サーバーの起動、外部ファイルは不要です。このHTMLファイルだけを別の場所にコピーしても遊べます。

## ルールと操作

- 中央4×4に赤・青・黄・緑を各4枚配置して開始。
- 手番は赤 → 青 → 黄 → 緑。AIモードでは赤だけを人間が操作します。
- 自分の石で縦・横・斜めにはさんだ他の色の石が、自分の色に変わります。混色の列も返せます。返した石からの連鎖取りはありません。
- はさめる石のないマスには置けません。置き場所のヒントは出しません。
- 置ける場所がない人は1.5秒の案内後、自動でスキップ。0枚になった色も同様です。
- 全員が置けなくなるか、盤が埋まると終了。最多枚数が勝ち。同率一位は引き分け。
- 4辺のストックは装飾です。予備の石の枚数による制限はありません。
- タップ・クリックで操作。キーボードは矢印とEnterに対応。
- ブラウザの「戻る」でホームに戻れます。その時点でAIと演出を中止します。
- 設定で音と動きの軽減を切り替えられます。モードと設定は保存可能な端末内だけに記憶します。対局途中の盤面は保存しません。

## AI

4色それぞれが自分に有利な手を選ぶMaxN探索（3手先・各段最大5候補）を使用します。角、角の隣のリスク、置ける場所の数、端の石、終盤の枚数と勝敗を評価します。AIの思考中や演出中は人間が代わりに打つことはできません。

## 開発と検証

Node.js 22以降。外部パッケージは不要です。

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
```

`src/` が編集元です。ビルドすると、同一内容の `4色オセロ.html` と `dist/index.html` を生成します。生成HTMLは直接編集せず、編集後は再ビルドしてください。

- `src/engine.js` — DOMに依存しないルール
- `src/ai.js` — 4人用AI
- `src/app.js` — 操作、AI進行、演出、設定、WebMCP
- `src/style.css` — 駒・ボード・収納トレーと各画面サイズへの対応
- `src/index.html` — 画面構造
- `scripts/build.mjs` — 外部参照なしの単体HTMLを生成
- `tests/` — ルール、AI、単体HTMLの検証
- `TESTING.md` — 自動テストと実ブラウザ検証の記録

公開版も同じ単体HTMLを使用します。フレームワーク、CDN、外部フォント、API通信に依存しません。
