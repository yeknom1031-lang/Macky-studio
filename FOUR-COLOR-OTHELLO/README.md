# Irodory

自分の色ではさんで、一番多く。コンピューター3人との対戦と、同じ画面で交代する4人対戦ができるブラウザゲームです。

## すぐ遊ぶ

このフォルダーの **`Irodory.html` をダブルクリック**して、ブラウザで開いてください。HTMLにプログラム・見た目・音をすべて含めています。ネット接続、追加アプリ、サーバーの起動は不要。このファイルだけコピーして持ち運べます。

ブラウザ版: https://macky-four-color-othello.manbikun.chatgpt.site

## 対局前の設定

「ひとりで遊ぶ」を押すと、次の設定を選べます。

- 強さ: やさしい / ふつう / つよい
- 広さ: 6×6 / 8×8（基本）/ 10×10 / 12×12
- 自分の色: 基本４色と購入済みの特別色からランダム
- 最初の手番: １〜４番目を色とは独立に抽選
- 置ける場所の目印: 最初はオフ。対局中の設定からも変更可能

ひとり対戦は開始するたびに色と手番を再抽選します。「同じ設定でもう一局」も新しい抽選です。開始演出で自分の色と順番を案内し、スコアには「あなた」の目印を出します。色の並びもランダムで、その対局中は順番が固定です。同じ抽選結果が続くこともあります。4人対戦は従来どおり赤・青・黄・緑の順です。

## ルールと操作

- どの広さも中央4×4に4色を各4枚配置。手番１〜４番目の色を左上・右上・右下・左下に配置。
- 決まった４色の順で交代。縦・横・斜めの8方向で、他の色を自分の石ではさみます。
- 他の色が混ざった連続した列もすべて返せます。空きマスを越えたり、返した石から連鎖して取ることはありません。
- はさめる石のないマスには置けません。合法手がない人は1.5秒の案内後、自動スキップ。0枚になった色も同様です。
- 全員が置けなくなるか満盤で終了。最多枚数が勝ち。同率一位は引き分け。
- 開幕は各色が一度ずつ打つまで、まだ手番を終えていない色を０枚にする手は選べません。安全な手がなければ自動でパスします。
- タップ・クリック、または矢印キーとEnter / Spaceで操作。
- 対局中の「○の番」を押すとメニュー。次の手まで一時停止し、ルールブックや設定を開けます。
- 「降参する」→ 確認で対局を終了。ひとりモードは選んだ自分の色が降参し、1敗として1対局を記録します。AIの手番でも操作できます。コイン・購入品は減りません。4人モードでは現在手番の色が降参し、この卓の対局を終了します。途中の枚数で勝者は決めません。
- 4辺のストックは装飾で、使用枚数の制限はありません。
- ホームに戻るとAI・対局進行を中止。対局途中の盤面は保存しません。

## コインと着せ替え

ひとり対戦の単独勝利で、下記のコインを受け取れます。最多の引き分けは半額（端数切り捨て）。4人対戦、敗北、降参、中断はコイン対象外です。勝利報酬は1対局1回のみ。

| 強さ | 6×6 | 8×8 | 10×10 | 12×12 |
|---|---:|---:|---:|---:|
| やさしい | 30 | 40 | 55 | 70 |
| ふつう | 50 | 60 | 75 | 90 |
| つよい | 80 | 90 | 105 | 120 |

ボードはクラシック（無料）、ウォールナット（80）、オーシャン（120）、ミッドナイト（180）。特別な駒はアメジスト（50）、ローズ（70）、パール（90）。ボードは何度でも無料で着せ替えでき、購入した駒の色は自分の色の抽選候補に加わります。ゲームの強さには影響しません。コインはゲーム内専用で、課金はありません。

設定・コイン・購入品・戦績はブラウザ内に保存します。サイト版、ローカルHTML、別のブラウザ・端末の間では自動同期されません。「設定 → データを書き出す」でJSONを残し、移動先の「データを読み込む」で復元できます。読み込みは現在の保存データを置き換えます。ブラウザのデータ削除前やファイルを移動する前に書き出してください。保存が使えない環境では画面に案内します。

## AI

やさしい: 合法手からランダム。ふつう: 2手先・各段最大4候補。つよい: 3手先・各段最大5候補のMaxN探索。4色それぞれが自分に有利な手を選び、角・角の隣のリスク・合法手の数・端・終盤の枚数と勝敗を評価します。AIの手番や演出中に人間が代わりに打つことはできません。

## 開発と検証

Node.js 22以降。外部パッケージ不要。

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
```

`src/` が編集元です。ビルドすると同一内容の `Irodory.html`、旧名互換の `4色オセロ.html`、`dist/index.html` を生成します。生成HTMLは直接編集せず、編集後は再ビルドしてください。

- `src/engine.js`: DOMに依存しない可変サイズのルール
- `src/ai.js`: 3段階の4人用AI
- `src/match.js`: 降参可否と対局終了への移行
- `src/progression.js`: 商品・購入・装備・報酬・保存データの正規化と色・席の抽選
- `src/audio.js`: 接触ノイズと減衰共鳴による石の音、静かなBGM、定位・音量・発音管理
- `src/app.js`: 画面・対局進行・演出・設定・保存・WebMCP
- `src/style.css` / `src/index.html`: 各画面と見た目
- `tests/`: ルール・AI・経済処理・単体HTMLの検証
- `TESTING.md`: 自動テストと実ブラウザ検証の記録
- `ARTWORK.md` / `src/assets/table-atmosphere.jpg`: 生成背景素材とプロンプトの記録

公開版も同じ単体HTML。フレームワーク、CDN、外部フォント、API通信に依存しません。コインはローカルの遊び用データで、オンラインランキングや不正防止を要する通貨ではありません。

## 画面の演出

エメラルド・黒・ゴールドで統一したホーム、立体感のあるボード・駒・4辺のストック、手番カラーの点灯、対局開始と勝敗・降参の演出を実装しています。対局画面には小さなロゴ、手番・枚数・盤面を表示。「動きを少なくする」でアニメーションを省略できます。色・順番の開始案内は静止表示で短く残します。背景素材も含めて単体HTML内に収録しています。

## Irodory ロゴ

４色の駒と金属調のワードマークを画像生成し、ホーム・対局中のヘッダー・対局開始演出に使用しています。ロゴもHTMLに内蔵され、オフラインで表示できます。制作記録は `ARTWORK.md`。保存データの識別子は従来のままなので、ブラウザ版のコイン・購入品・設定を引き継ぎます。ローカル版はファイル名を変えると保存先が変わるブラウザもあるため、旧名の `4色オセロ.html` も同じ内容で更新しています。

## 石の音と演出

電子音の周波数スイープを廃止し、短い接触ノイズ・硬い駒の減衰共鳴・小さな跳ね返りを重ねた音へ変更しています。録音素材ではなく、端末内で合成するオリジナルの効果音です。置くときの「パシッ」と返すときの「パチン」を分け、８種類の微差、左右の定位、同時発音の抑制とコンプレッサーで自然な響きに調整しました。音声ファイルのダウンロードは不要です。

設定には効果音とBGMのオン／オフ、音量、試聴ボタンがあります。BGMは端末内で合成する控えめなアンビエント音で、タブを離れると一時停止します。ブラウザの自動再生制限に対応するため、タップやキー操作で音を準備します。端末自体の消音はゲームから解除できません。ホームに戻る・降参・新しい対局・ミュート・タブが非表示になると残った音を停止します。

駒は置く瞬間に軽く沈み、返るときは持ち上がって着地。実際の着地に音を合わせています。着手位置の短い輪、反転後の淡い光、スコア更新の動き、勝利時の短いチャイムと金色の粒子を追加。置ける場所の目印はこれまでどおり設定でオフにできます。
