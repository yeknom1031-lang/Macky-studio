HOW TO PLAY

ルールブック

オンライン対戦

初回にニックネームを決めて参加します。４色の対戦で、色と手番はランダム。待機室に最初に入った人がホストとなり、盤面の広さ・1手の持ち時間・補充AIの強さを変更できます。ホストが退出・切断したら次の参加者が引き継ぎ、設定は残ります。4人そろえば開始、最初の待機から1分で足りない席をAIが担当します。ひとりでも参加できます。

1手の持ち時間は30・45・60・90秒からホストが選びます。時間切れはAIが代わりに打ち、連続2回でその席を引き継ぎます。通信が切れた場合は60秒以内に戻ると復帰でき、その間も時間は進みます。降参するとあなたは負けとなり、残りの対局はAIが続けます。オンライン中はメニューや設定を開いても時間は止まりません。

勝利は70コイン、最多同点は35コイン。結果はサーバーが判定し、同じ結果を二重には受け取れません。コインと購入品はこのブラウザの保存データに反映されます。終局後は同じメンバーとの再戦か、新しい対戦相手を選べます。ニックネームと対戦・報酬データはCloudflareに保存します。ログイン登録は不要ですが、ブラウザのCookieを消すと同じオンラインプレイヤーとして復帰できなくなります。

通常の２色オセロ

ホームの「通常の２色オセロ」から、AI１人と対戦・２人で交代を選べます。基本は８×８、中央に黒２枚・白２枚を斜めに置き、黒から交互に打ちます。ひとりモードのあなたの色は毎回抽選します。縦・横・斜めにはさんだ相手の石を返し、置けなければ自動パス。双方が置けなければ終了し、石の多い色が勝ち、同数は引き分けです。２色では初手の保護ルールや特別色の抽選を使いません。ボードの着せ替え、強さ、ヒント、降参、ひとり対戦のコインは４色と共通です。

４色オセロ

自分の色ではさんで、いちばん多く。

  1. ４色で交代。 ひとりモードでは、自分の色と１〜４番目の手番を毎回抽選します。残りの３色がコンピューターです。順番はその対局中は変わりません。４人モードは赤 → 青 → 黄 → 緑の順です。
  2. 相手の石をはさむ場所に置く。 縦・横・斜めの８方向で、１枚以上はさめる空きマスに置けます。はさめないマスには置けません。
  3. 間の色は全部ひっくり返る。 自分以外の色が混ざっていても、途切れずにはさんだ石はすべて自分の色になります。空きマスを越えてはさむことはできません。
  4. 置けなければ自動でスキップ。 「置ける場所がありません」と表示して、次の人に進みます。０枚になった色もスキップします。
  5. 石の数で勝負。 盤が埋まるか、全員が置けなくなると終了。いちばん多い人が勝ち。最多の人が複数なら引き分けです。

最初の配置

どの広さでも中央４×４に、各色４枚ずつ置きます。１番目の色が左上、２番目が右上、３番目が右下、４番目が左下です。ひとりモードは色の並びもランダム。自分の色は購入済みの色を含めて抽選し、特別な色でも先手になるとは限りません。同じ色や順番が続くこともあります。全員が初めて打つまでは、まだ打っていない色を１枚もなくす手は置けません。

勝利とコイン

ひとりモードで勝つとコインがもらえます。強さ・広さによって30〜200コイン。最多で引き分けた場合は半分です。４人モードや途中で終了した対局は対象外。ボードは購入後に選んで着せ替えできます。購入した駒の色は次の対局から抽選候補に加わります。見た目は強さに影響しません。

途中で降参する

対局メニューの「降参する」から確認すると、その対局を終了します。ひとりモードでは負けとして１対局を記録し、コインは増えません。４人モードでは現在の手番の色が降参し、卓全体の対局を終了します。途中の枚数で勝者は決めません。

鬼レベル

ひとり対戦で「鬼」を選ぶと、１手に最大５秒を使って深く考えます。２色は相手の最善手を見込み、４色はそれぞれの色の利益を見込んで読みます。終盤では最後まで読むことを狙います。思考中もメニューを開いて降参・終了できます。鬼に勝つと160〜200コイン。

自分だけのコマ

ホームの「コマ工房」で形・配色・仕上げ・模様・マーク・文字を自由に組み合わせられます。文字は8文字まで、色・書体・大きさ・位置も変更できます。名前付きで24個まで保存でき、「保存したコマ」から使用・編集・複製・削除ができます。４色のひとり対戦では選んだ色を使い、オンラインと黒白の対戦では席の色を保ちます。形や装飾、文字はオンラインの相手にも見えます。選んだコマは次の対局から使われ、強さには影響しません。

便利な設定

「置ける場所を表示する」は最初はオフ。設定でいつでも切り替えられます。オンのとき、置けるマスにポインターを合わせると取れる相手の石が自分の色に点滅し、枚数が表示されます。矢印キーでマスを選んだときも確認できます。「動きを減らす」がオンのときは点滅せずに表示します。対局中はEscキー、または上の「○の番」でポーズ。演出・待ち時間・AIの思考が止まり、設定変更や降参ができます。「ゲームを続ける」かEscキーで再開します。設定画面でEscキーを押すとポーズ画面に戻ります。

４辺のストックは本物の予備の石をイメージした飾りです。使用枚数の制限はありません。
