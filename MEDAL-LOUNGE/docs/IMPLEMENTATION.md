# 実装仕様

## 重要な形状と座標

手前が+Z、奥が-Z、上が+Y。投入レールは手前 `(±1.82, 1.48, 2.08)` から奥 `(可変X, 0.62, -1.73)` へ下る開放溝です。円盤の面は垂直、縁が溝に接触している状態を描画します。角度変更時は転がり中のメダルもレールへ追従します。

レール上だけは拘束経路と距離に応じた回転で安定させ、出口でJolt剛体へ引き継ぎます。上段、落下、下段、積層タワーは剛体です。見えない力でユーザーのメダルを当たりへ移動する処理はありません。

上段の棚は周期3.2秒、前後振幅0.36。床面だけでなく下段へ届く押し出し面を持ちます。後方の固定壁は棚の全ストロークと重なり、奥にコインが抜けるすき間を作りません。

## 抽選と搬送

ボールの回収とリフト搬送は経路アニメーション。ルーレット上では実際の剛体球が外周壁・区切りと衝突し、静止または7秒後の位置から5区画を判定します。浅い皿の傾斜に相当する弱い外向き力を与えます。完全な実機測定モデルや認証された公平な乱数抽選ではなく、購入・換金のないゲーム内演出です。

タワー機の3段階は同じ抽選器で順番に抽選し、表示灯で進行を示します。物理的に3個のルーレットがある構成ではありません。

払い出しホッパーは横へ移動しながら盤面へメダルを落とします。タワーは可視の組み立て位置で積み、搬入・下降して剛体に切り替えます。

## 描画と負荷

Godot Mobile / Metal、独自の金属シェーダー、共有メッシュ・材質、環境反射、スポットライトの影、ガラス、発光。スクリーンスペース反射やパストレーシングは使用していません。

盤面の実体メダルは最大850枚。回収済みの剛体を再利用。払い出しはプレイヤーの投入用に80枚分の空きを残し、一時停止できるキューです。ボールは盤面に最大7個、レール上は最大14枚。上限で受け付けられない投入は消費しません。

UIは540×1080を基準に拡張し、iOSの安全領域を考慮。操作UIは日本語。Mac/iOSのシステムフォントを使用します。

## 永続化と終了

JSONを一時ファイルへ書いてflushし、前回ファイルをバックアップ後にrenameします。各台は独立して保存し、残高は共有。中断した抽選を待機キューへ戻すため、抽選途中に終了しても獲得ボールは消えません。

通信、課金、広告、分析SDK、カメラ、マイク取得は実装していません。音声は実行時の合成PCMです。GodotランタイムのライセンスはGodot公式のMITライセンスに従います。
