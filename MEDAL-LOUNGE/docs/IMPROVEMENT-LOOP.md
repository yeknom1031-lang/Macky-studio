# コンセプトへの改善ループ

## 基準画像と不変条件

外観：`concept-art/02-classic-pusher-gameplay-adult-v2.png`、`03-roulette-tower-gameplay-adult-v2.png`、`07-imperial-tower-aiming-v3.png`。
レール：`concept-art/11-royal-pusher-forward-rail-v5.png`。初期画像の砲台・POWER・FIREは採用しない。
ルール：`concept-art/gameplay-rules-v3.md`。無制限投入・新規プレイ・保存復元はV2から維持。

## V2で足りなかった点

- 筐体は画面の一部だけで、手前が広い空白。盤面と抽選器が小さい。
- 銀メダルは面の法線が縁と平均化され、皿状の強いハイライトで刻印を失っている。
- 単純な白い箱、平坦な背面、露出した抽選皿。濃紺・ボルドー・真鍮の実機感がない。
- 抽選は5区画の角度を時間で判定。ポケットへの落下がない。
- ROYALはボールごとに抽選しており、元の3色収集ルールと異なる。
- タワーの積層装置・ボールリフト・払い出しシュートの形状と実際の搬送が一致していない。

## 実施順と合格条件

1. 構図・メダル：空白を減らし筐体を画面いっぱいに。平坦な刻印面と細い縁を分離。実キャプチャでレール2本、上段、下段、落下縁、操作部を同時に識別できる。
2. 筐体：生成した印刷パネル、濃色の化粧板、真鍮／クローム枠、暖色ランプ、透明ガード。背景は弱く、メダルと抽選を主役に。
3. 遊び：物理ポケットへの入賞、目に見えるボール搬送、3色収集、段階抽選、積層・搬入、勝利の機械演出を確認。結果を単なるタイマー抽選で偽装しない。
4. 検証：回帰テスト、自然な連続投入、ボーナス一巡、保存復元、実アプリ操作。旧品質設定を維持し、同条件の負荷比較を残す。

各ループで実キャプチャ・テスト結果・再修正点を追記する。生成した理想図を実装結果として提示しない。iPhone実測・App Store公開の未完了を隠さない。

## 記録

- 開始：V2の実画面と元コンセプト／ルールを照合。上記の差を確認。

### 1. 構図と刻印

- 筐体のカメラを寄せ、下段を1.0延長。投入口・左右レール・上段・下段・前縁・操作部を1画面に収めた。
- コインの面と縁の平滑法線が混ざり、面が皿状に見える原因を修正。星／月桂樹の銀メダルを画像生成し、刻印のコントラストと微細な法線表現を調整。
- 多数の実キャプチャを比較。暗過ぎる金属反射、金色に寄る銀メダル、奥壁に半分埋まるルーレット、上端タイトルのUI重なりを順に修正した。

### 2. 筐体と生成素材

- `imagegen`の内蔵画像生成を3回使用。装飾インレイ・銀メダル・反射パノラマを作成し、実ゲームで使用。完全なプロンプトは `assets/generated/PROMPTS-V3.md`。
- 濃色の筐体、面取り、真鍮の支柱、クローム、ネジ、暖色灯、透明ガード、赤い押下ボタンを製作。進行ランプとカウンターは隠れない手元のパネルへ移した。
- 金色の丸板にしか見えなかった積層装置を、細いフレーム・送り出し口・可動パレットへ修正。概念画像を画面背景として貼ってゲームが完成したように見せる方法は使っていない。

### 3. 実体抽選・積層・遊び

- ROYALを3色収集→抽選、IMPERIALを3本のトラックの連続突破へ分離。5/15個の実体穴とガード、下降する物理蓋を実装。
- 穴への落下テストだけでは、蓋の位置ずれを見逃していた。閉鎖時のレイ判定を追加すると失敗し、AnimatableBodyの同期設定前に置いた座標が失われる原因を特定。設定順を修正して、開く前に決着しないこともテストに加えた。
- 個別剛体296枚の高積層は、摩擦・形状・睡眠・反復精度を変えても沈み込みが残った。標準円柱→32面凸形状、反復32/8も試し、採用しなかった。安静積層を移動可能な合計質量の剛体にまとめ、衝撃や傾斜で個々のメダルへ崩れる方式へ変更。保存・復元とプール再利用まで検証した。
- 盤面を深くした初期版は、90秒投入しても獲得ゼロ。研磨面の摩擦と実際に配置する初期メダルの積載を調整。見えない獲得用の押力や直接加算は使わず、両台で自然な獲得・ボール回収・タワー崩壊を確認した。

### 4. 検証・残る境界

- ソースの回帰、穴・蓋・色収集、タワー保存・崩壊、両台90秒投入をそれぞれ実行。詳細と最終値は `QA-V3.md`。
- V2と同じ操作の負荷比較を実施。V3はメダル数と装飾が増え、全指標では速くなっていない。数値と条件を `PERFORMANCE-V3.md` に明示した。
- 元コンセプトの方向性（密な銀メダル、暗色の大人向け筐体、大きな抽選、前→奥レール）は反映。オフライン生成画像と同一の写実性、実機と同一の摩擦・機構を達成したとは言わない。
- 最終ルール確認で元案の倍率枠も追加。ROYALの80枠で次回払出2倍を獲得し、保存・1回消費・360枚JPのテストを追加した。
- iPhone署名・実機検証はXcode/Team IDがなく未完了。Macロック中は手動ウインドウ操作も確認できない。これらをテスト成功数で完了扱いしない。

### 5. V5 — 読みやすさ・操作・次の目標

- V4実画面と前→奥レールのコンセプトを再確認。抽選上の表示が小さく、待機表示は進行に関係なく固定文。ボールの不足色・倍率・残り払い出しが分かりにくかった。
- 筐体内モニターを拡大して手前へ傾け、日本語の進行表示を追加。結果後は実際の残り払い出しへ戻る。下部の案内も消えた後に現在の目標を表示する。
- 背景の明るさを抑え、レバーへ金色の選択リングと機械的な目盛り・針を追加。初回描画で目盛り板がレバーを隠したため、板を下げて再描画し修正を確認。
- GUIに指を離したイベントを消費されると投入が続き得る経路を修正。解放・OSキャンセルを先に処理し、外へのスライドで長押し解除。同じレバーを複数の指が奪い合うことも防止。中断時は見た目のボタンも戻す。
- V4の説明と異なり旧 `on_jackpot` に画面全体への色被せが残っていたため削除。筐体ランプと入賞穴の光・ファンファーレは維持。
- 新規目盛りは共有描画にまとめ、非表示のFPS文字更新は停止。進行文字は最大5Hzで必要なときに更新。解像度やメダル形状、影、物理精度を削らない。
- 回帰156項目成功（新規28項目）。検証の範囲と残る制約は `QA-V5.md`。

### 6. V6 — 新台 PARTY FEVER

- 既存台を変えるのではなく、専用の電子3リール台を追加。画像生成4回で6図柄アトラス・看板・ステージ・装飾パネルを作成して実ゲームへ適用。
- 実際のレール出口5枚で1抽選、ボール搬送で3抽選、ディスコで2倍フィーバー、777で300枚の物理払い出し。図柄と結果は保存し、中断で引き直さない。
- 初回実描画で当選文字が舞台背景に埋もれていたため、筐体内の黒い表示板を追加して再撮影。紙吹雪120枚・ネオン電球32個は共有描画。4生成画像以外に手描きの代用ラスター素材は作っていない。
- 保存の再確認でレール途中のメダルをカウントし損なう経路を発見し、PARTY用の途中走行復元と追加テストを実装。音切替のキャッシュ解放も修正した。
- 詳細・比率・保存仕様・素材プロンプト・検証の境界は `PARTY-FEVER.md`。
