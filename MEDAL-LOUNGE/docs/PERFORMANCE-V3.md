# V3 描画・物理負荷 — 2026-09-22

## 条件

Apple M2、Godot 4.7.2、Metal 4.0 / Forward Mobile、540×1080、4x MSAA、影あり、90Hz物理。V2はコミット `5dca060` の独立コピー。両版とも同一の `tools/benchmark.gd`：IMPERIAL TOWER、払い出し180枚、150フレーム準備、600フレーム計測、12フレームごとに左投入。`--fixed-fps 60`、Engine.max_fps=0、VSync有効。各レンダリング試験は別々に実施。

## 観測値

| 項目 | V2 | V3最終 |
|---|---:|---:|
| 最終メダル数 | 594 | 906 |
| 描画コマンド | 181 | 284 |
| 描画プリミティブ | 2,214,572 | 3,699,724 |
| ノード数 | 1,517 | 2,384 |
| process中央値 | 7.168 ms | 7.156 ms |
| process P95 | 7.235 ms | 11.881 ms |
| physics中央値 | 2.747 ms | 3.014 ms |
| physics P95 | 3.308 ms | 3.829 ms |
| 600フレーム実時間 | 5,001.057 ms | 5,013.759 ms |

どちらも約120fpsの観測で、最終V3はメダルが約53%多く、15穴・搬送部・装飾も増えている。中央値のprocess時間はほぼ同じだが、P95と物理時間はV3の方が増えている。**V2より一律に軽くなった、iPhoneでも120fps出る、と結論してはいけない。** 物理結果や最終枚数が異なるため、純粋な同一シーンの比較ではない。

V3内の試行：速度/位置反復12/4ではphysics中央値3.278 ms、process P95 11.261 ms。10/2へ戻すとphysics中央値3.014 ms。少数試行の揺らぎがあり、全指標の改善ではない。描画内容を減らさずCPU予算に収めるため、安静タワーの集約・休止中の姿勢更新省略・メダル再利用・共有描画を採用した。

V1→V2で得た描画共有による削減は維持している。V3で増えた見た目の負荷は隠していない。64分割メダル、画像解像度、4x/8x MSAA、影、90Hz更新を維持する。積層の物理近似は `IMPLEMENTATION.md` に記載。

## 再現

```sh
godot --path . --resolution 540x1080 --fixed-fps 60 --script res://tools/benchmark.gd
```

ヘッドレスのルール試験をGPU性能として扱わない。通常起動の高画質設定は60fps上限。iPhone上の発熱・メモリー・継続性能、8x MSAAモードの長時間性能は未検証。
