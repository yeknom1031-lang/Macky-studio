# MEDAL LOUNGE

縦画面・左右2本の投入レールで遊ぶ、Godot製3Dメダルプッシャーです。2台のルール、物理メダル、ボール抽選、タワー生成、音、保存を実装しています。

## すぐ遊ぶ（このMac）

`Play.command`、または `build/v2/MEDAL LOUNGE.app` をダブルクリックしてください。改訂版の配布用は `build/MEDAL-LOUNGE-v2.zip` です。Godotなしでもアプリ版は起動できます。以前のビルドは上書きせず残しています。

起動後、好きな台の「新規でプレイ」を選びます。メダルは無制限のFREE PLAYです。課金・広告・換金・通信はありません。「続きから」は盤面を再開、「保存したプレイ」は新規プレイ前に保管した盤面を復元します。

### 操作

- 筐体手前の左右の黒いレバーをドラッグ：投入レールを手前の支点で左右に振る。
- 筐体の赤いMEDALボタン：その側のレールに1枚投入。長押しで連続投入。
- メダルは立ったまま手前から奥へ転がり、奥の上段で物理挙動に移る。砲台や発射力調整ではありません。
- 手前へ落ちたメダルだけを獲得。左右の溝に落ちたメダルは回収外。
- Macのキー操作：A＝左投入、D＝右投入、矢印＝最後に使ったレールの調整、Escape＝設定。
- 残高・補充・購入・待ち時間による投入制限はありません。筐体のOUTカウンターは獲得数であり、使える枚数ではありません。

## 2台のルール

### ROYAL MEDAL

二段の可動棚と、赤・青・緑のボール。ボールを手前に落とすと回収レーン・リフトを通ってルーレットへ移ります。ボール回収時に10枚を盤面へ払い出し。3色をそろえると次の抽選決着時に180枚のジャックポット。

ルーレットの通常枠は20 / 40 / 80枚。BALL枠は追加ボールと15枚、JP枠は180枚。払い出しは直接残高に加算されず、実際に盤面へ落ちます。

### IMPERIAL TOWER

中央28段・7列と左右18段の銀メダルタワーを物理配置。同じルーレットのJP枠を3段階続けて突破すると、260枚の払い出しと98枚の新タワー生成。通常枠でも21 / 35 / 49枚のタワー素材を獲得。積み上げ装置で組み立てた後、下段へ搬入します。JP以外の枠では段階が1へ戻ります。

## 保存・音・画質

- 台ごとに盤面・メダルの姿勢と速度・ボール・レール角度・払い出し残数・未完了抽選を保存。
- 12秒間隔、台選択、終了、アプリ中断時に自動保存。ファイル破損時は前回のバックアップを読みます。
- 「新規でプレイ」は現在の両台の盤面を保管してから初期化。音量・画質設定は維持します。保管ファイルは消さず、画面から直近6件を再開できます。
- 中断した抽選は再開時にやり直し。組み立て途中のタワーは素材へ戻して再生成します。
- BGM・ゲームセンター環境音・機械音を個別調整。すべてオリジナルの合成音です。
- 高画質＝4x MSAA・60fps上限、最高画質＝8x MSAA・30fps上限。**上限は目標でありiPhone実測値ではありません。**
- 画像生成したゲームセンター背景、ステンレス表面、銀メダル面を実際のゲームへ組み込みました。元画像・生成プロンプトは `assets/generated/` にあります。
- 金属用シェーダー、面取り付き銀メダル、環境反射、動的影、ガラス、発光を使用。オフライン画像のパストレーシングではなくMobileレンダラーによるリアルタイム描画です。
- 改訂版は共有描画（MultiMesh）、静的筐体の描画統合、休止中のメダル更新省略で軽量化。メダルの64分割形状・レンダリング解像度・MSAA・影・90Hzの物理精度は削っていません。

Macの保存先：`~/Library/Application Support/Godot/app_userdata/MEDAL LOUNGE/medal_lounge_v2.json`。保管先は同じ場所の `medal_lounge_archives/`。初回は旧 `medal_lounge_v1.json` があれば読み込みますが、旧ファイルへは書き込みません。

## iPhone版について

iOSの書き出し設定は用意済みです。Godot 4.7.2、Metal、縦画面、iPhone向け、iOS 18以降、gaming-tier対応端末を設定しています。古いiPhone向けの低品質モードは用意していません。

**署名済みiPhoneアプリと実機検証はまだ完了していません。** このMacには完全版Xcodeがなく、Apple Team IDも未設定です。iOS書き出しはTeam IDの検証で停止しました。iPhoneでのフレームレート、発熱、ノッチ・ホームバー、触覚、バックグラウンド復帰は実機確認が必要です。

仕上げの手順：

1. 完全版XcodeとiOS SDKをインストールする。
2. Godotの「プロジェクト → エクスポート → iOS」に本人のApple Team IDを設定する。
3. 出力するXcodeプロジェクトを開き、署名先と接続したiPhoneを選んで実行する。
4. 実機で画質・発熱・操作・保存を検証する。

Appleアカウントや証明書などの秘密情報をこのリポジトリへ保存しないでください。

## 開発・再ビルド

Godot **4.7.2** で `project.godot` を開き、F6ではなくF5で起動。物理エンジンはJolt、物理更新は90Hz、描画補間を有効にしています。

```sh
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot sh tools/check.sh
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot sh tools/build-mac.sh
```

テストはプレイヤーの保存を変更しません。主な実装は `scripts/main.gd`（画面・進行）、`scripts/machine.gd`（盤面・物理・抽選）、`scripts/art.gd`（3D形状）、`scripts/sound.gd`（合成音）、`scripts/profile.gd`（保存）です。

詳細は `docs/QA.md`、`docs/IMPLEMENTATION.md`、`docs/PERFORMANCE-V2.md`。`screenshots/v2-*.png` が改訂版の実ゲームキャプチャ、接頭辞のない画像は以前の版です。
