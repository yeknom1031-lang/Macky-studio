# SKY VOYAGER — 雲海の航海者

飛行船で浮遊島を巡る、ブラウザで動くオリジナルの3Dアクションアドベンチャーです。第1章「風を継ぐ者」は市場での準備、遺跡の探索、船長戦、帰還と強化まで一周遊べます。

このMacでは `遊ぶ.command` をダブルクリックすると、ブラウザが開いて遊べます。デスクトップにも `雲海の航海者.command` を置いています。ログインやSitesは使いません。

## 戦闘と全身アニメーションの更新（2026-10-23）

- **J / クリック**：一閃 → 返し斬り → 風斬りの3段コンボ。次の入力を終わり際に受け付け、技ごとに腰・肩・足・剣の軌道を変えました。
- **K**：溜めて振り下ろす重斬り。盾に強く、敵の体勢を崩せます。通常斬りよりSPを多く使います。
- **G**：正面ガード。攻撃が当たる直前に押すとパリィになり、敵をひるませて反撃を強化します。背後からの攻撃や落下は防げません。
- **Q**：方向入力に応じた低姿勢の回避。攻撃が重なる瞬間の見切り回避では短いスローモーションと反撃の好機が発生します。
- 弓は引く・放つ・戻るを分け、矢は実際に放つ瞬間だけ消費。敵も振りかぶり・攻撃・隙・のけぞり・倒れる動作を使い分けます。石の守り手には両腕の叩きつけを追加。
- 剣の軌跡、金属の火花、足元の粉塵、命中音、短いヒットストップ、減衰する画面の揺れ。Escで揺れを切り替えられます。
- 船長は斬撃・斬り返し・大振りを使い分けます。船長戦のカメラを近づけ、戦闘通知とHP表示の重なりを解消しました。

タイトルの **「戦闘稽古」** ですぐ試せます。Escから「遺跡で稽古」「船長と稽古」を選べ、稽古の結果で通常の冒険記録を変更しません。通常の冒険から稽古へ移る際は、その直前の冒険を保存します。

人物アニメーション、演出・音、独立レビューを3エージェントで分担。主人公28メッシュ・石兵27メッシュを維持し、戦闘演出は13メッシュの固定プールで再利用します。新しい画像生成は行っていないため、画像予算は累計26枚・残り974枚のままです。

3段コンボ、ガード・パリィ、重斬り、弓、回避、強化薬を使った船長撃破、通常記録の復帰をMacの実画面で確認しました。検証記録は `qa/combat-review-20261023.txt`。大規模商用ゲームと同等の映像品質や60fpsを保証するものではありません。

## 船・人物・島の仕上げと軽量化（V4 / 2026-10-22）

生成画像をさらに13枚（船4、人物4、島5）制作して3D素材として組み込みました。この画像生成予算での累計は26枚、上限1,000枚中の残りは974枚です。使用数と全プロンプト・元画像の所在は `IMAGE-BUDGET.json` と3つの `*-V4-PROMPTS.json` に記録しています。

- 船：青緑と金の重ね板、彫金の船首、船尾の船室と舷窓、生成紋章入りの帆、滑車・縄梯子・甲板のロープ。
- 人物：滑らかな肩と袖、握った指、革のブーツ、重なる前裾・マント、薬師の植物柄・船長の赤い刺繍服。肌と布の質感を分け、眉も調整。
- 島：生成した樹皮・葉の枝・苔石・紫の花・看板、屋根飾り、ベンチ、鎖の手すり、欠けた遺跡の柱、灯台の展望台。
- 軽量化：人物の素材を共有し主人公のメッシュ数68→28。遠い装飾島の小石・花を90/120mで切替。遺跡の同じ視点では描画三角形526,712→286,950（約45%減）。FPSはブラウザの状態で変動するため固定値を保証していません。
- Esc の一時停止画面に **画質：おまかせ / くっきり / 軽快** を追加。メニュー中や非表示タブの描画負荷も減らしました。
- 低フレームレートでも移動速度や効果時間が遅くならないよう、シミュレーションを短い時間刻みに分割。長い停止からの復帰は急な移動を防ぐため最大0.15秒に制限。

ローカルで航行・上陸・薬の購入・剣と弓の戦闘・ジャンプ・風車の橋・保存と再開を確認済み。3人のサブエージェントの制作・レビューに加え、統合試遊で肌の誤った布模様、肩の穴、浮いた旧舷窓を発見して修正しました。記録は `qa/v4-review-20261022.txt`。

## 遊び方

1. 最初の桟橋で **E** を押して市場へ上陸します。武器屋・薬屋・船大工の近くで **E** を押すと購入できます。
2. 桟橋へ戻って **E** で乗船。**M** の航海図から風車の遺跡を選ぶと自動航行します。到着したら **E** で上陸します。
3. 風向計を北へ合わせ、橋をつなぎます。守り手を倒し、奥の宝箱から風の紋章を入手します。
4. 航海図から鉄爪船長の旗艦へ。赤い攻撃範囲を避け、大技のあとの隙に反撃します。
5. 撃破後は市場で船を強化し、開放された雲下の庭園や他の島を探索できます。

薬は上陸中に使用します。透明薬は18秒間、近づきすぎない限り発見を防ぎ、攻撃すると解除されます。防御薬は25秒間被ダメージを45%軽減、怪力薬は25秒間与ダメージを1.65倍にします。回復薬は55回復し、満タン時は消費しません。効果中の同じ薬も消費しません。

画面のタッチボタンでも基本操作ができます。PCのキーボードとマウスでのプレイを推奨します。

## 起動

Macでは **`遊ぶ.command` をダブルクリック**してください。Python標準機能でこのMacだけに接続できるサーバーを起動します。次回も同じファイルから開けます。インターネット接続やアカウントは不要です。

ゲーム中のセーブはブラウザに保存されます。次回も同じブラウザで開いてください。

Node.jsのある環境でこのフォルダから `npm run dev` または `node server.mjs` を実行し、表示されるローカルURLを開きます。依存パッケージのインストールは不要です。PythonのHTTPサーバーなどで `dist` を配信しても動作します。HTMLファイルを直接開くと画像読み込みや保存が制限されるためHTTP経由で開いてください。

`dist/` が配布する静的ファイルの一式です。実行時の外部CDN・外部API・有料サービスは不要です。WebGLとJavaScriptが必要です。

## セーブ

同じブラウザ・同じURLの保存領域へ記録します。買い物、上陸、宝箱、撃破、10秒ごとに自動保存されます。メニュー中は時間が止まります。タブから離れた場合も自動停止します。

同じ保存先を複数タブで同時に操作しないでください。独立テストには `?profile=任意の名前` で保存領域を分けられます。公開サイトとローカルプレビューのセーブは別です。保存先を消去すると記録も失われます。

## 構成・素材

- `dist/models.js`: 船、人物、島、建物、小物のオリジナル3Dモデルとアニメーション。
- `dist/game.js`: 移動、戦闘、買い物、パズル、航路、保存、描画。
- `dist/combat.js`: コンボ・入力予約・接触タイミング・防御判定。
- `dist/combat-fx.js`: 固定プールの剣軌跡・火花・衝撃輪・粉塵と音。
- `dist/assets/`: 内蔵画像生成ツールで作成した薬アイコン、航海図、石畳、木目。プロンプトは `ASSET-PROMPTS.txt` と `MATERIAL-PROMPTS.txt`。
- `dist/vendor/three.min.js`: Three.js（MIT License）。
- `qa/`: 実際の操作による独立レビューとスクリーンショット。

目標コンセプト画像に合わせて、帆と船体、青緑と暖色の配色、浮遊島、HUD、風車、甲板での戦闘を実装しています。生成画像と同じ造形密度やライティングを完全に再現するものではありません。
