# SKY BUILDER 3D

空に浮かぶコースを遊び、その場で作り変えられる3Dアクションゲームです。

## 起動

Macでは `PLAY.command` をダブルクリックするだけで起動できます。初回だけmacOSの確認が表示された場合は、右クリックして「開く」を選んでください。

ターミナルから起動する場合は、このフォルダで次を実行し、表示されたURLをブラウザで開きます。

```bash
python3 -m http.server 8765
```

- 移動: A/D または左右矢印キー
- ジャンプ: Space / W / 上矢印
- カメラ: 横スクロールで自動追従
- モード切替: 画面上部、または E
- 編集: ドラッグで連続配置、右クリックまたは消しゴムで連続削除
- 編集画面移動: Shift + ドラッグ
- 拡大・縮小: マウスホイール

編集画面では足場の幅を1・3・5マスから選べます。スタートとゴールが揃うと、プレイ可能表示が緑色になります。

コースはブラウザの `localStorage` に保存されます。
